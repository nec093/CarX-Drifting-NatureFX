## 0. 「ときどきゲームが落ちる」（HANDOFF 未解決 3）の原因

ログ（`Player.log` 2 回分と `kino/output.log`）で、落ちる直前は毎回「**DLSS モード切替と同時に解像度が 1916x997 → 3840x2054 になった**」直後で、GPU メモリは予算の 98%（10.6 / 10.85 GB）だった。コードから、重なった原因は次の 3 つ。

| # | 状態 | 内容 |
|---|---|---|
| X1 | ✅ | **範囲外読み（本命）**: `NativeEngine.BeginFrame` が `ScreenSize` にカメラの表示解像度（3840x2054）を入れる一方、画面色バッファ `screen_` は描画解像度（Ultra perf. なら 1280x685）で確保される。反射・ガラスの `ScreenVisibility`（`NFXReflect.hlsli`、`Glass.hlsl`）はルート SRV（境界チェックなし）を `ScreenSize.x` のストライドで読むので、アップスケールを選んだ瞬間にバッファの 9 倍先まで読み、GPU がページフォルトする（DXGI_ERROR_DEVICE_HUNG）。DLAA では一致していたので出なかった。→ `PrepareScreen` が `ScreenSize` を描画解像度で上書き |
| X2 | ✅ | **VRAM**: 4K では Mod の画面サイズ依存の確保だけで約 4 GB（1916x997 の約 4 倍）。切替の瞬間は旧サイズの一式も残る。→ 置き換えたバッファの保持を 10 → 3 フレームに、掃除を毎フレーム（`NativeEngine.Update`）に。RR 用ガイド 2 枚とランプマスク履歴 2 枚（4K で約 400 MB）は使うときだけ確保 |
| X3 | ✅ | **タイムアウト後の解放**: `WaitRenderIdle` は 5 秒で諦めて戻り、`DlssResize` はその直後に DLSS フィーチャとテクスチャを解放していた。GPU がメモリ追い出しで数秒止まる状況（まさに X2）で、使用中の資源を壊す。→ 待ちが間に合わなければ解放せず、そのフレームの DLSS を見送る |

ゲームでの確認: F8 で DLSS を Quality / Balanced / Ultra perf. にし、ウィンドウと 4K を往復しても落ちないか。`kino/output.log` の `GPU memory` が切替後に元の水準へ戻るか。

## 4. 問題なしと確認した契約

- P/Invoke 36 本の署名、`TraceEventData` 8448 B、`NrdEventData` 328 B、`DlssEventData` 192 B、`Frame` cbuffer の添字（0..51、ライト 52 + k×512、2100 float）、`Record` 128 B、各 kind のバッファのストライド、空データ 2,490,368 B の内訳、3D 霧の箱と煙のオフセット、`NFX_NativeBridge` 全カーネルのディスパッチ数と要素数。
- NRD の 2D モーション（uv、prev − cur）、`roughness = sqrt(alpha)`、SIGMA の遮蔽物距離の復元、REBLUR の hitDist パラメータ。DLSS の `DepthInverted` / `IsHDR` / `AutoExposure`、品質値、ジッターの符号関係（HDRP と同じ）。
- `_NFX_*` 170 余りのプロパティ名と型、パス番号（RTShadow / RTReflect / SunExact / Post / Upscaled / Atmosphere）、`VariantProfileStripper` が残すパス。
- プロファイルの解析は InvariantCulture、`Settings.Migrate` v2〜61 に例外経路なし、ファイル IO はすべて try/catch 内。
- Hillaire のスカイビュー・Bruneton の透過率の生成と参照のパラメータ化、SH の詰め方、太陽の円盤 `lux/(π r²)`。

## 5. ゲームでの確認の仕方

- X1〜X3: DLSS の各モードとウィンドウ ↔ 4K の往復で落ちないか。`GPU memory` が切替後に戻るか。
- C1: 長時間（数時間）の走行後も煙・雨・ブレーキ光が動いているか。
- C2: マップを何度も切り替え（DXR 1.2 の太陽影オンでも）、device removed が出ないか。
- R1〜R3: DLSS Quality / Balanced でカメラを振ったときの二重像、霧やランプの帯が車に遅れずついてくるか、アップスケールの揺れが減ったか。
- R4: 霧のある公式トラックでトラックの霧が残るか。
- R5: 走行中に Native sky をオフにして、雲の影の斑点や古い霧が残らないか。
- R7: 夜、月の影がチラつかないか。
- R10: 雲をオフにしたセッションでも 3D 霧の箱とタイヤスモークが出るか。
