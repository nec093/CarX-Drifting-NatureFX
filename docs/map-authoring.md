# NatureFX マップ作者向け仕様

KN マップの作者が「このマップをどう見せたいか」を NatureFX に伝えるための仕様です。
指定がなければ、NatureFX はマップの中身をシェーダー名・オブジェクト名のルールから推測して処理します。この仕様の指定を使うと、推測ではなくマップ側の指定で見た目を決められます。

指定はすべて**マップのデータそのものに入れられ**、NatureFX を入れていない環境では何も変わりません（0 章）。

- 0〜7 章はすべて実装済みです。まだ予定のものは「（予定）」と書いてあります（詳しくは [ROADMAP.md](ROADMAP.md)）。ゲームでの確認状況は [HANDOFF.md](HANDOFF.md) にあります
- F8 の **Map** タブで、読み込んだプロファイル・マーカーの数・各機能の状態（何をしているか、何を待っているか）を確認できます。**Show markers** で、マーカーの箱と光源を画面に重ねて描けます
- マップの指定は F8 > Map の **Use map profiles**（既定オン）がオンのときだけ使います。素材・発光・草木の色・3D の草・藪は NatureFX のシェーダーで描くので、F8 の **Replace shaders**（シェーダーの作り直し）もオンである必要があります。デカール・水たまりと水面・局所的な霧・粒子は F8 > Map の **Map effects**（既定オン）で切り替えます

## 前提：Kino のタグとの関係

Kino はオブジェクト名の先頭のタグで物理面と当たり判定を決めます。

| タグ | 意味 |
|---|---|
| `road_` `kerb_` `gravel_` `dirt_` `grass_` `sand_` `snow_` `icyroad_` | 走行面（物理面の種類） |
| `nocol_` | 当たり判定なし |
| `alpha_` / `alphaCol_` / `alphaLit_` | 透過（なし / 当たり判定あり / 法線マップあり） |

NatureFX の指定は、**このタグを変えずに**足せます。タグの直後に名前を続ける今の付け方はそのまま使えます。

- NatureFX 専用のオブジェクトは `nfx_` で始めます。メッシュを持つものは、当たり判定を付けないよう `nocol_nfx_` で始めます
- 既存のオブジェクトへの指定は、名前ではなく「プロファイル」（1 章）と「頂点カラー」（2 章）で行います
- 置き換えのルール（`[rules]`）や `[materials]` などの判定は、マテリアル名とオブジェクトの階層パスの両方に当てます

## 0. マップへの持たせ方

Kino Content SDK のマップのビルド（`Assets/Editor/Maps/MapsBuilder.cs`）は、マップのシーンを 1 つのアセットバンドルにするだけで、オブジェクトやコンポーネントを削ったり書き換えたりしません。シーンに置いたものは、空のオブジェクトも無効にしたコンポーネントも、そのままゲームに届きます（テストマップ `test_map` で確認済み）。

### 原則

- **NatureFX がない環境で、描画・当たり判定・挙動が変わらないものだけを使う**
- **自作のスクリプト（MonoBehaviour）は使わない**。ゲームにそのコードがないため「スクリプトが見つからない」という警告がログに出て、中のデータも読めなくなります
- **TextAsset などを単体でバンドルに入れない**。シーンを入れたバンドルにはシーン以外を入れられない（Unity の決まり）ため、文字のデータは標準のコンポーネントに入れます

### 持たせ方

| 何を | 置き方 | NatureFX なし | NatureFX あり |
|---|---|---|---|
| マップの設定（プロファイル。1 章） | `nfx_profile` というオブジェクトに標準の **TextMesh** を付け、`text` にプロファイルの全文を入れる。MeshRenderer は無効にする | 何も描かれない | 文字列を設定として読む |
| 範囲や位置（ゾーン、水たまり、霧の範囲など。3・4 章） | **空のオブジェクト** `nfx_<種類>_<プリセット>`。Transform の位置・回転・拡大率が、箱の中心・向き・大きさ（m）になる | 何もしない | マーカーとして読む |
| 光源・反射プローブ・デカール・局所的な霧・粒子 | HDRP / Unity の**標準のコンポーネントを無効にして**置く。オブジェクト名は `nfx_` で始める（4.3） | 無効なので何も起きない | 条件（夜など）に合わせて有効にする |
| 草木の揺れ方・空の開け具合（2 章） | 頂点カラー | HDRP/Lit は頂点カラーを使わないので変わらない | 揺れ方や積もり方に使う |
| 草・森・藪・水面を置く面（5・7 章） | **MeshFilter だけ**（MeshRenderer なし）のオブジェクト `nocol_nfx_<種類>_<プリセット>` | 描画されない | 面の上に草などを生やす |

- 残る副作用は、無効のまま置いたコンポーネントのテクスチャなどで、マップのファイルと読み込み時のメモリが少し増えることだけです
- これは Kino Content SDK（Unity）で作る `.knmap` の場合です。OBJ だけで作るマップには空のオブジェクトやコンポーネントを入れられないため、メッシュのマーカー（4.2）とマップ外の設定ファイル（1 章）を使います

## 1. マップごとの設定ファイル（プロファイル）

### 置き場所

プロファイルは 2 か所に置けます。中身の書式は同じです。

| 置き場所 | 用途 |
|---|---|
| **マップの中**：`nfx_profile` オブジェクトの TextMesh の `text`（0 章） | 配布するマップ。マップと一緒に届くので、別のファイルを配る必要がない |
| **マップの外**：`kino/config/NatureFX/maps/<シーン名>.nfx` | 公式のコースや OBJ のマップ、作者の手元での調整 |

- 両方ある場合は、**マップの外のファイルを優先**し、マップの中のプロファイルは使いません（丸ごと置き換え）
- `<シーン名>` は、そのマップを読み込んだときのシーン名です（コースは複数のシーンを読み込むので、ファイルのある最初のシーン）。F8 > Map に表示されます
- F8 > Map のボタン：**Reload map profile**（編集後の読み直し）、**Create template**（プロファイルがないときにひな形を書き出す）、**Export to file**（マップの中のプロファイルをマップの外のファイルに書き出す。手元で調整して、またマップに戻すため）、**Copy camera position**（4.4）

### 書式

INI に近い形式です。行頭または空白の直後の `#` から行末まではコメントです（正規表現の中の `#` は、直前に空白がなければそのまま使えます）。同じセクションで同じキーを 2 回書くと、後のものを使います。知らないキーはログに警告を出して無視します。

```ini
# Sample Touge 用
[map]
name = Sample Touge
inheritGlobalRules = true      # true（既定）: このファイルのルールの後に既定のルールも使う
vertexColors = true            # 2. の頂点カラーを使う（既定 false: 頂点カラーを無視）
foliageWind = true             # 画面の葉を風で揺らす（幹が葉と別のメッシュのマップだけ。既定 false: 影だけ揺れる）

[rules]
# NatureFX.rules.txt と同じ書式（<ゲームのシェーダーの正規表現> | <名前の正規表現> => <NatureFX のシェーダー>）。
# 上から順に判定し、最初に当てはまったものを使う
(?i)^HDRP/Lit$ | (^|/)alpha_trees_ => NatureFX/Foliage
(?i)^HDRP/Lit$ | (^|/)road_ => NatureFX/LitAccumulation

[defaults]
# マップを読み込んだときの初期値。利用者がメニューで変えた値は上書きしない
wind.direction = 135           # 度。0 = +Z（北）、時計回り
wind.strength = 0.5            # 0..2
wind.gust = 0.4                # 0..1
season = autumn                # none / spring / summer / autumn / winter（下の表）
snow = 0.0                     # 0..1
leaves = 0.4
dust = 0.1
wetness = 0.0
fog.distance = 1200            # m。0 でフォグを足さない
fog.height = 80                # m（既定 80）
groundblend = 0.35             # m。物体が地面の色をもらう高さ（7.8）。既定 0.35、0 で切る

[zone.summit]
# 3. の天候ゾーン（nfx_zone_summit）の中での値
snow = 0.6
fog.distance = 300
wind.strength = 1.2
blend = 40                     # m。ゾーンの縁からこの距離で外の値となめらかにつなぐ
priority = 10                  # ゾーンが重なったときは大きいほうが勝つ
```

### セクションの一覧

| セクション | 内容 | 章 |
|---|---|---|
| `[map]` | `name` `inheritGlobalRules` `vertexColors` `foliageWind` | 1・2 |
| `[rules]` | シェーダーの置き換えのルール（既定のルールより先に判定） | 1 |
| `[defaults]` | 風・季節・蓄積・霧・接地の初期値 | 1 |
| `[zone.<id>]` | 天候ゾーンの中の値 | 3 |
| `[markers]` | 座標で置くマーカー | 4.4 |
| `[grass]` | `auto = true` で `grass_` の面にも 3D の草。`preset`（既定 `wild`） | 5.1 |
| `[foliage]` | 木の種類・透過光・色のばらつき・紅葉の色 | 5.2 |
| `[emissive]` | 夜に光るマテリアル | 6.2 |
| `[probes]` | `auto = true` で道路沿いに反射プローブ。`spacing`（m、既定 60） | 6.4 |
| `[night]` | 星と遠くの街明かり | 6.5 |
| `[clouds]` | `sea = <高さ m>` で雲海 | 6.6 |
| `[materials]` | 現実の素材の割り当て、再帰反射、鏡 | 7.1 |
| `[terrain]` | 法面と崖のトリプラナー | 7.5 |
| `[paint]` | 泥はね・水しみ・轍 | 7.8 |

### `season` の意味

`season` は `[defaults]` の蓄積値をまとめて決める近道です。個別の値（`snow` など）を書いた場合はそちらを優先します。`[defaults]` の `season` は、木と草の季節の色（5.3）にも使います。

| season | snow | leaves | dust | wetness |
|---|---|---|---|---|
| `spring` | 0 | 0.1 | 0.1 | 0.2 |
| `summer` | 0 | 0 | 0.3 | 0 |
| `autumn` | 0 | 0.5 | 0.15 | 0.1 |
| `winter` | 0.5 | 0.1 | 0 | 0.3 |

### 利用者の設定との優先順位

1. 利用者がメニューで変えた値（最優先）
2. 天候ゾーンの値（カメラがゾーンの中にいるとき）
3. マップの `[defaults]`
4. NatureFX の既定値

- 「利用者が変えた値」は、マップを読み込んだ時点からスライダーを動かした値です。動かしたキーは、次のマップを読み込むまで利用者の値を使います。スライダーのない `fog.distance` `fog.height` `groundblend` は、いつもマップの値です
- NatureFX は利用者の設定を書き換えません。別のマップに移る、または **Use map profiles** をオフにすると、利用者の値がそのまま戻ります（オフのときは 2・3 とマップの素材・発光・ルールをすべて無視します）
- 天候のプリセット（Manual 以外）を選ぶと、蓄積の値（snow など）はプリセットのものになります。風の強さ・向きと霧はプリセットの上からも効きます
- `fog.distance` は霧の減衰距離、`fog.height` はカメラの高さから霧が薄れていく高さです（峠のどの標高でも車のまわりに霧が残るよう、霧の底はカメラの高さに合わせて動きます）。雨や霧の天候では距離が短くなります

## 2. 頂点カラーによる指定

メッシュの頂点カラーに、揺れ方と雪の積もり方を書き込みます。`[map] vertexColors = true` のマップでだけ使います（頂点カラーのないメッシュは白 (1,1,1,1) として読まれ、「全体が最大に揺れる」誤った見た目になるため）。

| チャンネル | 使い道 | 0 | 1 |
|---|---|---|---|
| **R** | 風の影響の強さ | 揺れない（根元・幹） | 最大に揺れる（枝先・葉先・草の先） |
| **G** | 揺れの位相のずらし | — | — （0..1 を 0..2π に変換。隣り合う株が同じ動きをしないように乱数を入れる） |
| **B** | 硬さ | 草のように柔らかい | 動かない |
| **A** | 空の開け具合 | 屋根の下・橋の下・トンネル | 空が完全に開けている |

- R・G・B は `NatureFX/Foliage` の揺れに、A は雪・落ち葉・濡れの付き方に使います。レイトレーシングの影の揺れは頂点カラーを使いません

### 付け方の目安

- **木**：R は高さに比例（地面 0、樹冠の上 1）、幹は R = 0・B = 0.8 前後
- **草の株・ササ**：R は株の根元 0、先端 1。G は株ごとに乱数
- **路面・地形**：R = 0。A は森の中や崖の下で下げると、雪や落ち葉が自然にまばらになる
- **橋の下・トンネル**：A = 0 にすると雪・落ち葉・濡れが付かない

### 注意：OBJ 形式の KN マップ

OBJ には頂点カラーの標準的な書き方がありません（`v x y z r g b` は一部のソフトだけの拡張で、アルファもありません）。
頂点カラーは **Kino Content SDK で作る `.knmap`** でだけ使える前提です。OBJ 形式のマップでは `vertexColors = false` のまま、名前のルールだけを使ってください。

## 3. 天候ゾーンのマーカー

マップの一部だけ天候を変えるための、見えない箱です。

### 名前

```
nfx_zone_<id>
```

- `<id>` は英数字と `-` だけ。プロファイルの `[zone.<id>]` と対応します（対応するセクションがないゾーンは警告を出して無視します）
- 空のオブジェクトで置き、Transform の拡大率で箱の大きさ（m）を決めます。回転させた箱もそのまま判定します
- OBJ のマップでは、直方体のメッシュ `nocol_nfx_zone_<id>` で置けます（4.2）

### 中で変えられる値

`[zone.<id>]` には `[defaults]` と同じキーに加えて、次を書けます。`season` は蓄積の値の近道としてだけ効きます（木の色は `[defaults]` の `season` に従います）。

| キー | 意味 | 既定 |
|---|---|---|
| `blend` | 縁から外の値へなめらかにつなぐ距離（m） | 20 |
| `priority` | ゾーンが重なったときの優先度（小さい順に重ね、大きいほうが勝つ） | 0 |

判定はカメラの位置で行います。カメラがゾーンに入ると、縁から `blend` の距離をかけてゾーンの値に近づきます。

### 例

- 峠の頂上付近だけ雪：`nfx_zone_summit` を頂上に置き、`snow = 0.6`
- 谷沿いだけ霧：`nfx_zone_valley` を谷に沿って置き、`fog.distance = 250`
- トンネルの中だけ風を止める：`nfx_zone_tunnel` を置き、`wind.strength = 0`

### 予定

- `nfx_shelter_<id>`：箱の中を「屋根の下」として扱い、雪・落ち葉・濡れを付けない（頂点カラーの A を塗れないマップ向け）
- `nfx_wind_<id>`：局所的な風（谷を吹き上がる風など）の向きと強さ

## 4. マーカーの共通書式

5〜7 章の「置くもの」は、マーカーで指定します。マーカーの置き方は 4 通りあり、どれも同じものとして読みます。

| 置き方 | 使える所 | 位置・大きさ・向き |
|---|---|---|
| 4.1 空のオブジェクト | SDK のマップ（推奨） | Transform の位置・拡大率・回転 |
| 4.2 メッシュのマーカー | OBJ のマップ | メッシュの境界の箱。向きは名前のキー |
| 4.3 無効にした標準のコンポーネント | SDK のマップ | Transform と、コンポーネント自身の設定 |
| 4.4 プロファイルの `[markers]` | どこでも（公式のコースなど） | 座標とキー |

### 名前

```
nfx_<種類>_<プリセット>[__<キー>-<値>]...
```

- 例：`nfx_light_sodium`、`nfx_puddle`、`nfx_volume_mist__density-0p5`
- `<種類>` は `zone` `light` `probe` `grass` `fx` `decal` `puddle` `water` `volume` `forest` `shrub` `shrubproto` のどれか。知らない種類は警告を出して無視します
- `__<キー>-<値>` で、プリセットの値を一部だけ変えられます。小数は `0p5`（= 0.5）、負の数は `m30`（= −30）と書きます。値のない `__<キー>` は `on` と同じです。Blender や Unity が付ける `.001` や ` (1)` のような番号は無視します
- メッシュを持つマーカーは `nocol_` を前に付けます（`nocol_nfx_...`）。Kino が当たり判定を付けないようにするためです
- 無効にしたオブジェクトも探すので、マーカーはオブジェクトごと無効にしておいてもかまいません

### 4.1 空のオブジェクト

- 位置は Transform の位置、箱の大きさは拡大率（m）、向きは回転です（光やデカールは、オブジェクトの前（+Z）の向き）
- 何も描かず、当たり判定もないので、NatureFX がない環境に影響しません

### 4.2 メッシュのマーカー（OBJ のマップ向け）

- `nocol_nfx_<種類>_...` という名前の直方体のメッシュ（MeshRenderer 付き）を置きます。位置と大きさはメッシュの境界の箱です
- 向きは名前のキー `yaw`（0 = +Z（北）、時計回り。風向きと同じ）と `pitch`（0 = 水平、90 = 真下）で指定します
- NatureFX がない環境では見えてしまうため、マテリアルは透明（アルファ 0）にしておきます。NatureFX は読み込み時に描画を止めます
- MeshRenderer のない `nocol_nfx_...`（MeshFilter だけ）は、マーカーの箱ではなく「生やす面」として読みます（草・森・藪・水面）

### 4.3 無効にした標準のコンポーネント

HDRP / Unity の標準のコンポーネントを付けたオブジェクトを、`nfx_` で始まる名前で置き、**コンポーネント（またはオブジェクト）を無効にしておきます**。NatureFX が条件に合わせて有効にします。明るさや色、テクスチャなどは、Unity のエディターでそのコンポーネントに設定した値をそのまま使います。

| 種類 | コンポーネント | NatureFX がすること |
|---|---|---|
| `light` | Light（HDRP の光源） | `when` に合わせて点灯・消灯、ちらつき、影付きの数の管理（6.1） |
| `probe` | Reflection Probe | 時刻・天候の変化に合わせて描き直す（6.4） |
| `decal` | Decal Projector | 有効にする。ただしゲームの HDRP 設定でデカールが無効なので、今は表示されない（7.2） |
| `volume` | Local Volumetric Fog | `when` に合わせて有効にする（7.4） |
| `fx` | Particle System | Map effects がオンの間、再生する（5.4） |

- 名前のプリセットは省略できます（`nfx_light`）。その場合は、点灯の条件など NatureFX 側の動きだけをキーで決めます（`nfx_light__when-dusk`）
- プリセットを書いた場合（`nfx_light_sodium`）は、コンポーネントがなければ NatureFX がプリセットの光源を作り、あればコンポーネントの値を優先します

### 4.4 プロファイルでの配置

マップを編集できない場合（公式のコースなど）のために、同じものをプロファイルの `[markers]` に座標で書けます。

```ini
[markers]
# 種類_プリセット = x, y, z [, キー=値 ...]   （ワールド座標、m。size は 幅x高さx奥行き、既定 1x1x1）
light_sodium    = 120.5, 34.0, -88.2, yaw=90, pitch=70
volume_mist     = 300, 10, 450, size=80x20x200
puddle          = 41.0, 12.3, 5.5, size=4x0.3x2
```

- 公式のコースで位置を探すには、F8 > Map の **Copy camera position** でカメラの位置をクリップボードにコピーします
- 面が要るもの（草・森・藪・水面）と、コンポーネントを使うもの（4.3）は `[markers]` では置けません

### 数の上限

| 種類 | 上限 | 超えた場合 |
|---|---|---|
| `light` | 描画は 64 個（影付きは 8 個） | カメラに近い順 |
| `probe` | 16 個 | 自動の配置は一番遠いものを外す |
| `decal` | 512 個（描くのは 32 個） | カメラに近い順 |
| `puddle` | 16 個 | カメラに近い順 |
| `fx` | 32 個 | カメラに近い順、80 m より遠いものは止める |
| `volume` | 32 個 | カメラに近い順 |

## 5. 草・植生

### 5.1 立体の草

NatureFX が地面の上に草の葉を大量に描きます。板の草（`alpha_grass`）では出ない、密度と立体感を出すためのものです。

**生やす場所**
- `nocol_nfx_grass_<プリセット>` のメッシュの面の上（草を生やす範囲の地面のコピーを、**MeshFilter だけ**で置く）
- `[grass] auto = true` のとき、`grass_` で始まる走行面にも自動で生やす（`preset` で種類、既定 `wild`）。静的バッチされた面には生やせません

**プリセット**

| プリセット | 見た目 | 高さ |
|---|---|---|
| `lawn` | 刈り込まれた芝 | 5〜10cm |
| `wild` | 路肩の雑草（季節で枯れる） | 20〜50cm |
| `susuki` | ススキ（秋に穂が出る） | 80〜150cm |
| `sasa` | ササ（冬も緑） | 40〜80cm |
| `moss` | 苔（湿った日陰で濃くなる） | 1〜2cm |

キー：`density`（本/m²）、`height`（倍率）、`hue`（色相のずらし、度）

**動き**
- 風で揺れる（風の向き・強さ・突風をそのまま使う）
- タイヤが通ると倒れ、しばらくで起き上がる（タイヤ跡マップの圧縮を使う）
- 雪が積もると埋もれる。雪の深さより低い草は描かない

**描き方と負荷**
- 8m 四方の区画ごとに草のメッシュを作り、カメラが近づいたら作って離れたら捨てます。遠い区画ほど葉を減らします（全部 → 1/2 → 1/4）
- 届く距離は F8 > Map の **3D grass distance**（既定 60m、`lawn` はその半分、`moss` は 3 割）。密度は **3D grass density**
- 描画は `NatureFX/Foliage`（HDRP の光と影が付く）なので、**Replace shaders** がオンのときだけ出ます
- 生やす面のメッシュは「読み取り可能」である必要があります
- 影を落とすのはカメラから 25m までで、レイトレーシングの影には入りません

### 5.2 葉の透過光と色のばらつき

`[foliage]` に、木の種類ごとの見え方を書きます。左辺は `[rules]` と同じ判定（マテリアル名とオブジェクトの階層パスに当てる正規表現）です。

```ini
[foliage]
(?i)alpha_trees_cedar   => type=conifer,   translucency=0.3, variation=0.15
(?i)alpha_trees_broad   => type=deciduous, translucency=0.7, variation=0.3, autumn=red
(?i)alpha_trees_ginkgo  => type=deciduous, translucency=0.6, autumn=yellow
(?i)alpha_sasa          => type=bamboo
```

| キー | 意味 |
|---|---|
| `type` | `conifer`（針葉樹）/ `deciduous`（広葉樹、既定）/ `bamboo`（竹・ササ）/ `grass` |
| `translucency` | 逆光のとき、葉が透けて明るく見える強さ（0..1）。既定は種類ごと（針葉樹 0.25、竹 0.45、草 0.5、広葉樹 0.6） |
| `variation` | 木ごとの色のずらし（0..1、既定 0.2）。木の位置から乱数を作るので、データは要らない |
| `autumn` | 広葉樹の紅葉の色：`red` / `yellow` / `mixed`（既定）/ `brown` |

- `[foliage]` に当てはまった `HDRP/Lit` のマテリアルは `NatureFX/Foliage` に切り替わります
- 透過光は「逆光のとき法線を太陽側へ傾けて明るくする」近似です

### 5.3 季節の色

季節によって、`type` ごとに色を変えます。

| type | 春 | 夏 | 秋 | 冬 |
|---|---|---|---|---|
| `deciduous` | 明るい若葉 | 濃い緑 | `autumn` の色 | 葉を落とす（枝だけになる） |
| `conifer` | 緑 | 緑 | 少し褐色寄り | 暗い緑 |
| `bamboo` | 緑 | 緑 | 緑 | 葉の縁が白く枯れる（隈笹） |
| `grass` | 明るい緑 | 緑 | 黄土色に枯れる | 枯れ草 |

- 季節は F8 > Weather > Season で選びます。Auto は、天候のプリセットが Autumn・Snow ならその季節、それ以外はマップの `[defaults] season`。どれもなければ（None も）色を変えません
- 季節を変えると、約 30 秒で次の季節へ進みます。木ごとに少しずつずらして変えます
- 冬の広葉樹は、葉の切り抜きを強めて葉を減らします。落とした葉も、レイトレーシングの影には残ります

### 5.4 生き物と舞うもの

`nfx_fx_<プリセット>` の箱の中に、細かい粒を出します。条件（季節・時刻・天候）に合うときだけ出ます。自分で作った Particle System を無効にして `nfx_fx` という名前で置くこともできます（4.3。条件は見ず、Map effects がオンの間だけ再生します）。

| プリセット | 出るもの | 条件 |
|---|---|---|
| `fireflies` | ホタル | 夏の夜、雨でないとき |
| `leaves` | 舞い落ちる葉 | 秋。風が強いほど多い |
| `petals` | 桜の花びら | 春 |
| `moths` | 灯りに集まる虫 | 夏の夜。点いている光源マーカーの近くにも自動で付く |
| `dust` | 日差しの中の塵 | 晴れの日中 |
| `pollen` | 綿毛・花粉 | 春〜初夏 |

キー：`amount`（倍率）

- 季節を決めていない（None）ときは、季節に縛られないもの（夏の夜のホタルと虫、落ち葉が多いときの落ち葉、塵）だけ出ます

### 5.5 遠景の森

- `nocol_nfx_forest_<conifer|broadleaf|mixed>` のメッシュ（MeshFilter だけ）の面に、木を十字の板（インポスター）で 2km 先まで並べます。マップで作っていない山肌を埋めるためのものです
- キー：`density`（100m² あたりの本数、既定 2）、`height`（m。既定 22、`broadleaf` は 14）
- 風で揺れ、季節の色・冬の落葉も付きます。遠くは本数を減らし、影は 200m まで

### 5.6 藪（スキャンの低木）

スキャンした低木を GPU インスタンシングで数千本描きます。距離で 3 段階に切り替えます。

| 距離 | 描くもの |
|---|---|
| 近く（F8 > Map の **Scanned shrubs up to**、既定 25 m） | スキャンそのもの |
| その 3 倍まで | ビルボードクラウド：スキャンを 20〜50 枚の板に近似したもの |
| 300 m まで | オクタヘドラルインポスター：上半球の N×N 方向から焼いた絵を、見る向きで切り替える 1 枚の板 |

どの段階も `NatureFX/Foliage` で描くので（**Replace shaders** が必要）、風・季節・雪・透過光が効きます。独自エンジンのシーンには全部の低木の板の束が入り、影と反射に出ます。

マップには、低木ごとの「ひな形」と、生やす面を置きます。

```
nocol_nfx_shrubproto_<名前>__frames-8     空のオブジェクト（どこに置いてもよい）。frames はインポスターの N（既定 8）
  nfxproto_lod0       スキャンのメッシュ（MeshRenderer はオフ）。原点に立たせる
  nfxproto_cloud      板の束のメッシュとマテリアル（オフ）
  nfxproto_impostor   1 枚の板とインポスターの絵のマテリアル（オフ）
nocol_nfx_shrub_<名前>+<名前>__density-0p8__scale-1p2    生やす面（MeshFilter だけ、読み取り可）
```

- `density` は 1 m² あたりの本数（既定 0.15）で、F8 > Map の **Thicket density** を掛けます。`scale` は大きさの倍率で、1 本ずつ ±25 % ばらつきます。40° より急な面には生やしません
- 板の束とインポスターの絵は `tools/kino_sdk/bake_shrub_lods.py`（Blender）と `shrubs_to_png.py` で作ります。テストマップでは `NfxShrubs.cs` の `ShrubProto` と `ShrubArea` が組み立てます（区画 N4）
- 季節の色は `[foliage]` でマテリアル名（`nfxshrub_`、スキャンの葉のマテリアル）に付けます

## 6. 光

### 6.1 光源マーカー

`nfx_light_<プリセット>` の位置に HDRP の光源を置きます。Unity のエディターで無効にした Light を置けば、その明るさ・色・形のまま、NatureFX が点灯を管理します（4.3）。

| プリセット | 種類 | 色温度 | 明るさ | 既定の向き |
|---|---|---|---|---|
| `sodium` | 高圧ナトリウム灯（橙色の街灯） | 2000K | 12000 lm | 真下 |
| `mercury` | 水銀灯（古い青白い街灯） | 4200K | 10000 lm | 真下 |
| `led_street` | LED の街灯 | 4500K | 9000 lm | 真下 |
| `tunnel` | トンネル照明（橙） | 2000K | 4000 lm | 真下 |
| `vending` | 自動販売機の前面 | 6000K | 1500 lm | `yaw` の向き |
| `floodlight` | 投光器（駐車場など） | 5000K | 30000 lm | `yaw`・`pitch` |
| `beacon` | 黄色の点滅灯 | 黄 | 800 lm | 全方向 |
| `lantern` | 提灯・常夜灯 | 2200K | 300 lm | 全方向 |

キー：`lm`（明るさ）、`k`（色温度）、`range`（届く距離 m）、`yaw` `pitch`、`spot`（スポットの角度）、`shadow`（`on` / `off`）、`flicker`（0..1。古い蛍光灯のちらつき）、`when`（`night`（既定）/ `dusk`（夕方から）/ `always`）、`ies`（`off` で配光なし。6.7）

- 点灯は太陽の高さで決めます。夕方からの点灯は太陽の高さ 6〜10°、夜の点灯は −1〜3°（街灯ごとにずれて、一斉に点かない）。ナトリウム灯・水銀灯は数秒かけて明るくなります
- 向き：`yaw` `pitch` を書けばそれを、書かなければ空のオブジェクトの回転を、回転していなければプリセットの向き（街灯は真下）を使います
- `vending` は面光源の代わりに前へ向けた広いスポットです（面光源はレイトレーシングのランプに含まれないため）
- 霧の中ではランプの光の筋が見えます
- 光源の器具のモデルはマップ側で置いてください（マーカーは光だけです）
- F8 > Map の Lights に、点いている数・描いている数・影付きの数が出ます

### 6.2 発光マテリアル

`[emissive]` で、マテリアルを夜だけ光らせます。

```ini
[emissive]
(?i)led_sign       => nits=800,  k=6500, when=always
(?i)window_house   => nits=60,   k=2700, when=night, random=0.6
(?i)vending_front  => nits=400,  k=6000, when=always
```

| キー | 意味 |
|---|---|
| `nits` | 明るさ（cd/m²、既定 100）。現実の単位なので、露出と自然に合う |
| `k` | 色温度（既定 6500） |
| `when` | `night`（既定）/ `dusk` / `always` / `off` |
| `mask` | 光らせる範囲：`bright`（既定。色テクスチャの明るい所）/ `alpha`（テクスチャのアルファ）/ `full`（面全体） |
| `random` | 点いている割合（0..1）。家の窓などを場所ごとに点けたり消したりする |
| `flicker` | ちらつき（0..1） |

- `random` と点灯のずれは、ワールド座標の 6m 四方の区画ごとに決まります（Kino のマップは静的バッチでオブジェクトがまとめられ、オブジェクト単位で区別できないため）
- `[emissive]` や `[materials]` `[terrain]` に当てはまった `HDRP/Lit` のマテリアルは、置き換えルールがなくても NatureFX のシェーダーに切り替わります（雪や濡れも付くようになります）

### 6.3 再帰反射

白線・標識・デリネーター（視線誘導標）・ガードレールの反射板が、ヘッドライトの光を来た方向へ返して光って見えるようにします。

`[materials]`（7.1）で `retro` を付けます。

```ini
[materials]
(?i)markings        => asphalt_paint, retro=0.6
(?i)warning_sign    => metal_painted, retro=1.0
(?i)delineator      => plastic, retro=1.0
```

- `retro = 1` は標識の反射シート（約 300 cd/lx/m²）、`0.6` は白線程度（約 5）です。光が返るのはヘッドライトの近くだけなので、運転席の視点では強く、車の後ろの高い視点では弱く光ります
- 対象はカメラに近い 4 台分のヘッドライトです
- 雨で白線が水に覆われると、反射が弱まります（現実と同じ）

### 6.4 反射プローブ

車体や濡れた路面に映り込む景色を、その場所に合ったものにします。

- `nfx_probe` を、映り込みが変わる所（森の中、トンネル、開けた所）に置きます。空のオブジェクトなら箱の大きさが影響範囲（2m 以下なら 60×30×60m）、無効にした Reflection Probe ならその影響範囲の設定を使います（4.3）
- `[probes] auto = true` なら、道路に沿って `spacing`（既定 60m）ごとに自動で置きます。道路の形はマップから分からないため「車が走った所」に置き、16 個を超えたら一番遠い自動のプローブを外します
- 時刻・天候が変わったら、カメラに近いものから 1 フレームに 1 面ずつ描き直します
- F8 > Map の **Map reflection probes** で切り替えます。独自エンジンの空（F8 > Sky & fog の **Native sky**、既定オン）の間は使いません（空の映り込みは独自エンジンの空、近くの物はレイトレーシングの反射が受け持つため）

### 6.5 夜の背景

```ini
[night]
skyline = 180      # 街明かりの方角（度。0 = +Z、時計回り）。書いたときだけ街明かりを置く
distance = 3000    # m
spread = 70        # 広がる角度
height = -150      # カメラからの高さ（m。麓の街なら負）
lights = 900       # 灯りの数
stars = true       # 星（既定 true）
```

- 星は夜に出て、雲が多いと隠れます。Native sky のときは独自エンジンが、オフのときはトラックの空が HDRP の Physically Based Sky の場合だけ NatureFX が描きます。`stars = false` でどちらも消えます
- 街明かりは夜にだけ点きます（光の点だけで、街の上の空の明るさはありません）

### 6.6 空と雲

- 雲は天候の雲量に合わせて増え、山に影が流れます（F8 > Sky & fog の Clouds and stars）
- 雲海：`[clouds] sea = <高さ m>` で、朝と雨上がりに雲の層がその高さ（上面）まで下りてきます。峠の上から谷を見下ろす絵になります。雲海は HDRP の体積雲で描くので、**Native sky がオフのときだけ**出ます
- 遠くの山が青く霞みます（F8 > Sky & fog の **Distant haze**）

### 6.7 街灯の配光とレイトレーシングの影

- `sodium` `mercury` `led_street` は道路に沿って細長く広がる配光（バットウィング）、`tunnel` は広く均一、`floodlight` は中心が強い配光です。道路の向きは光源の x 軸（`yaw` で回す）です。`ies=off` で配光なし
- **Ray traced shadows for every lamp**（既定オン）なら、街灯の影はすべてレイトレーシングで付き、「影付き 8 灯」の制限はなくなります。対象はカメラに近い 128 灯までで、1 画素あたり、16 灯までは全部から、それより多いと 8 候補から選んで影を付けます（ReSTIR の最初の段階）

## 7. 素材とオブジェクト

### 7.1 素材の指定

`[materials]` で、マテリアルに現実の素材を割り当てます。素材ごとに、濡れ方・汚れ方・経年変化が変わります。

```ini
[materials]
(?i)road_asphalt     => asphalt_old
(?i)masonry          => masonry, moss=0.6
(?i)guardrail        => metal_galvanized, rust=0.2
(?i)concrete         => concrete, stain=0.4
(?i)rock             => rock, moss=0.3
(?i)curve_mirror     => mirror
```

| 素材 | 濡れたとき | 経年変化（キー） |
|---|---|---|
| `asphalt_old` / `asphalt_new` | 暗くなり、水たまりができる。新しいほど黒く粒が細かい | `wear`（ひび・白っぽさ） |
| `asphalt_paint` | 滑らかに光る | `wear`（かすれ） |
| `concrete` | 濃い灰色にしみる | `stain`（雨だれの黒い筋） |
| `masonry` / `rock` | 継ぎ目から先に濡れる | `moss`（日陰・上向きの面に苔） |
| `metal_galvanized` / `metal_painted` | 水滴が玉になる | `rust`（錆。縁と下側から） |
| `glass` | 水滴が流れ落ちる | `dirt` |
| `plastic` / `wood` / `soil` | それぞれの吸水の度合い | `dirt` |
| `mirror` | 水滴が付く | 完全な金属の鏡になる（7.7） |

キー（どれも 0..1。素材の名前の後に書くと、その素材の値を上書きします）：

| キー | 意味 |
|---|---|
| `porosity` | 濡れたときの暗くなり方（吸水） |
| `moss` `rust` `stain` `wear` `dirt` | 上の表の経年変化 |
| `beading` | 水滴が玉になる度合い |
| `retro` | 再帰反射（6.3） |
| `antitiling` | テクスチャの繰り返しを目立たなくする（六角形のタイルでずらす） |
| `variation` / `variation_size` | 大きな範囲の明るさ・粗さのむら / その大きさ（m、既定 20） |
| `groundblend` | 接地のなじませの高さ（m。7.8。0 でこの素材だけ切る） |

### 7.2 デカール

`nfx_decal_<プリセット>` の箱の中の地面に、上から模様を描きます。ゲームの HDRP 設定ではデカールが無効なので、NatureFX のシェーダーが描きます（NatureFX のシェーダーの面にだけ出ます）。無効にした Decal Projector を `nfx_decal` という名前で置くこともできますが、ゲームがデカールを有効にしない限り表示されません（4.3）。

| プリセット | 模様 |
|---|---|
| `crack` | 路面のひび割れ（既定） |
| `patch` | 補修跡（色の違うアスファルトの継ぎはぎ） |
| `oil` | 油染み（濡れると虹色に光る） |
| `leaves_pile` | 落ち葉の吹き溜まり（落ち葉の量に合わせて増える） |
| `sand` | 砂・砂利の散らばり |
| `skid` | 古いブラックマーク（ブレーキ跡） |
| `moss_edge` | 路肩の苔・土の汚れ |
| `slow_dots` | 減速を促す破線（車線を横切るブロックの列） |
| `zebra` | ゼブラ（導流帯：枠と斜線） |
| `speed_30` / `speed_40` / `speed_50` | 路面の速度表示（+z の側から読める向き） |
| `joint` | 橋・伸縮の継ぎ目 |
| `manhole` | マンホールの蓋 |
| `worn_line` | かすれた白線 |

キー：`yaw`、`opacity`

- 模様は NatureFX が描いた 128px の画像です。空のオブジェクトの拡大率が大きさ（x：幅、z：長さ、y：上下に届く範囲。小さすぎるときは 4×1×4m）、Y 軸の回転（または `yaw`）が向きです
- 描くのはカメラに近い 32 個まで。雪や落ち葉はデカールの上に積もります

### 7.3 水たまりと水面

- `nfx_puddle`：雨で水がたまる所。箱の中央から水が広がり、強い雨で約 1 分半で満ち、やむと 10 分ほどかけて引きます。雨粒の波紋と映り込みも付きます。キー `amount`（0..1、既定 1）。カメラに近い 16 個まで、NatureFX のシェーダー（`NatureFX/LitAccumulation` など）の面にだけ出ます
- `nocol_nfx_water_<プリセット>`：常に水がある所。水面の形のメッシュを **MeshFilter だけ**で置きます

| プリセット | 水面 |
|---|---|
| `stream` | 沢・小川。`yaw`（なければ Y 軸の回転）の向きに流れる |
| `gutter` | 側溝。雨で水位が上がる（キー `rise`、既定 0.08m） |
| `pond` | 池。風でさざ波が立つ |

- 水面は不透明の暗い面です（映り込みで水に見せる）

### 7.4 煙・湯気・霧の源

`nfx_volume_<プリセット>` の箱の中に、局所的な霧を置きます（HDRP の Local Volumetric Fog に動くノイズを貼る）。自分で設定した Local Volumetric Fog を無効にして `nfx_volume` という名前で置くこともできます（4.3。`when` だけに従います）。

| プリセット | 見た目 | 条件 |
|---|---|---|
| `mist` | 谷を這う霧（既定） | 早朝、雨上がり |
| `steam` | マンホール・側溝の湯気 | 寒い日（雪がある・冬） |
| `smoke` | 煙突・焚き火の煙 | `when` で指定（既定 いつも） |
| `road_steam` | 雨上がりの路面から立つ湯気 | 雨がやんだ後 10 分以内の晴れ間 |
| `haze` | 遠くの霞 | 晴れた日中 |

キー：`density`、`when`（`always` / `night` / `dusk` / `day`）、`yaw`（煙が流れる向き。既定は風向き）

- 条件が合うと 8 秒ほどかけて濃くなり、外れると薄れて消えます。カメラに近い 32 個まで
- 描くのは、**Native fog**（既定オン）なら独自エンジンの 3D の霧（カメラに近い 64 個の箱）、オフなら HDRP のボリューメトリックフォグです（表示中は NatureFX がオンにします。ゲームのフレーム設定で無効なら出ません）

### 7.5 法面と崖（[terrain]）

```ini
[terrain]
(?i)cliff_|slope_ => triplanar, tile=4, steep=rock_mat, flat=grass_mat, slope=0.55, blend=0.15, noise=0.5, maptile=4
```

| キー | 意味 |
|---|---|
| `triplanar` | 色テクスチャを 3 方向から貼る（急な面で縦に伸びない） |
| `tile` | テクスチャ 1 枚の大きさ（m、既定 4） |
| `steep` / `flat` | 急な面・平らな面に使う、マップ内のマテリアルの名前（その色テクスチャを使う）。`steep` がなければ地の色を灰色の地層模様にした岩肌 |
| `slope` `blend` `noise` | 岩肌になり始める傾き（0 平ら〜1 垂直、既定 0.55）、境目の幅（既定 0.15）、境目の乱れ（既定 0.5） |
| `maptile` | `steep` `flat` のテクスチャ 1 枚の大きさ（m、既定 4） |

- 変わるのは色だけです（法線マップはメッシュのまま）
- HDRP/Lit の法線マップはそのまま使えます。視差オクルージョン（POM、`_PIXEL_DISPLACEMENT` + ハイトマップ）も NatureFX のシェーダーで効きます

### 7.6 冬の路面

- 寒い日（雪がある・冬）に路面が濡れて雨が止んでいると、1 分ほどかけてブラックアイス（つるつるの氷の膜）になります。晴れた昼は薄くなります
- 雪の日は、車が走った所に轍ができ、その脇に雪が押しのけられて積もります（タイヤ跡マップから）

### 7.7 カーブミラー

- 鏡の面のマテリアルに `[materials]` で素材 `mirror` を割り当てます（完全な金属の鏡になる）。映る景色はレイトレーシングの反射なので、Ray traced reflections が必要です

### 7.8 接地・汚れ・散らばるもの

独自エンジンが「地面の地図」（カメラの周り 128 m、12.5 cm 間隔、真上から見た地面の色・高さ・向き・路面か地面か）を作り、次の 4 つがそれを使います。F8 > Map の **Ground detail** で切り替えられます（独自エンジンが必要。塗る汚れとデトリタスは **Map effects** もオンのとき）。地面として扱うのは、地形（`terrain`）と、動かない幅 6 m 以上の平たいメッシュです。そのうちマテリアル名かメッシュ名に `road`・`asphalt`・`tarmac` を含むものを路面とします。

- **接地のなじませ**: 岩、擁壁、縁石、支柱、木の根元など、地面に刺さっている物の下の方が地面の色になります。下ほど濃く、境目はノイズで崩れます。高さはマップの既定値（`[defaults] groundblend`、m）か、素材ごとの値です。

  ```ini
  [materials]
  (?i)retaining_wall => concrete, groundblend=0.6
  (?i)guardrail_post => metal_galvanized, groundblend=0.15
  (?i)sign           => metal_painted, groundblend=0      # 0 でこの素材だけ切る
  ```

  草の葉と抜きの葉っぱ（カード）には効きません。
- **高さを使った混ぜ方**: 苔・汚れ・土ぼこり・落ち葉・雪が、表面の低いところ（石の隙間、ひび、目地）から先にたまります。高さマップのあるマテリアルはそれを使い、ないものは色の明るさ（暗いところが低い）を使います。設定は不要です。
- **塗る汚れ（`[paint]`）**: 位置を指定して、泥はね・水しみ・轍を描きます。点は `x,y,z`（ワールド座標、m）を `;` でつなぎ、`|` の後ろにオプションを書きます。

  ```ini
  [paint]
  # 路肩の泥はね: 幅 width m、地面から height m の高さまで
  mud   = 120,402.1,-30; 160,403.0,-12; 210,404.2,6 | width=1.5 height=0.6 strength=0.8
  # 擁壁の下の水しみ: 壁の足元の線、そこから height m 上まで（既定 1.0）
  stain = 300,410,80; 340,411,95 | height=1.2
  # 轍の黒ずみ: 路面の上、幅 width m（既定 0.4）
  rut   = 120,402.1,-29.2; 210,404.2,6.8 | width=0.35 strength=0.6
  ```

  頂点カラーの代わりに、メッシュに手を入れずに描けるようにしたものです。カメラの周り 256 m を 0.5 m 単位で描き、カメラが 64 m 動くと描き直します。
- **細かいもの（デトリタス）**: 路面と地面の境目の 2 m 以内に、小石・落ち葉・小枝の 3D の粒をまきます。F8 > Map の **Debris** で密度を変えられます（0 で切る）。カメラが 24 m 動くと、周りに置き直します。

## 8. map generator からの自動書き出し（予定）

map generator の設定（`config/<name>.yaml`）と生成物から、NatureFX 用のデータを自動で作る予定です（[ROADMAP.md](ROADMAP.md)）。

- map generator（Python）が、プロファイルの本文と、マーカー・光源などの一覧（位置・向き・大きさ・種類）を JSON で書き出す
- Unity でシーンを組み立てる `MapBuilder.cs` が、その JSON から `nfx_profile`（TextMesh）、空のオブジェクト、無効にした Light などを置き、メッシュに頂点カラーを書き込む

| map generator の要素 | NatureFX への書き出し |
|---|---|
| `trees_*`（枝葉のカード） | 頂点カラー R = 高さ ÷ 樹高、G = 木ごとの乱数、A = 林の密度から。`[foliage]` `conifer` / `deciduous` |
| `trees_bark` | 頂点カラー (0, 0, 0.8, 1) |
| `grass` / `sasa` / `shrubs` | 頂点カラー R = 株の中の高さ、G = 株ごとの乱数。`[foliage]` `grass` / `bamboo`。路肩の地面に `nocol_nfx_grass_wild` |
| 路面・地形 | 頂点カラー (0, 0, 1, 1 − 樹冠の被覆率) |
| `markings` | `[materials]` `asphalt_paint, retro=0.6` |
| `guardrail` | `metal_galvanized, rust=0.15`。反射板（`delineator`）に `retro=1.0` |
| `warning_sign` / `route_sign` | `metal_painted, retro=1.0` |
| `led_sign` | `[emissive]` `nits=800, when=always` |
| `masonry` / `rubble` / `rock` | `masonry` / `rock`、`moss` は林の中ほど高く |
| 道路の縦断の低い所・待避所 | `nfx_puddle` |
| 側溝 | `nocol_nfx_water_gutter` |
| 林に囲まれた区間・開けた区間の境目 | `nfx_probe` |
| 谷側の低い所 | `nfx_volume_mist` |
| 電柱・待避所の照明（設定にあれば） | `nfx_light_sodium` などの無効にした Light |
