# NatureFX マップ作者向け仕様（草案）

KN マップの作者が「このマップをどう見せたいか」を NatureFX に伝えるための仕様です。
NatureFX はマップの中身を推測で処理しています（シェーダー名・オブジェクト名のルール）。この仕様で、推測ではなくマップ側の指定で見た目を決められるようにします。

指定はすべて**マップのデータそのものに入れられ**、NatureFX を入れていない環境では何も変わりません（0 章）。

> **状態**：草案です。下の「実装状況」にあるとおり、ほとんどは未実装です。実装時に細部が変わる可能性があります。

## 実装状況

| 機能 | 状態 |
|---|---|
| Kino のタグ接頭辞（`road_` `alpha_` など）による自動の振り分け | **実装済み**（既定のルール） |
| 0. マップへの持たせ方（マップ内のプロファイル、空のオブジェクト、無効にしたコンポーネント） | **読み取りを実装済み**（マップの中の `nfx_profile`、空のオブジェクト、無効にしたコンポーネント、MeshFilter だけの面。それを使う機能は各段階で追加） |
| オブジェクトの階層パスでのルール判定 | **実装済み** |
| 1. マップごとの設定ファイル | **実装済み**（`[map]` `[rules]` `[materials]` `[emissive]` `[markers]` `[defaults]` `[zone.*]` `[probes]`。`[defaults]` と ゾーンはゲームで未確認） |
| 2. 頂点カラーによる指定 | **実装済み・ゲームで未確認**（R・G・B は `NatureFX/Foliage` の揺れ、A は雪・落ち葉・濡れ。レイトレーシングの影の揺れは頂点カラーを使わない） |
| 3. 天候ゾーンのマーカー | **実装済み・ゲームで未確認** |
| 4. マーカーの共通書式（設定ファイルでの配置を含む） | **実装済み**（読み取りと非表示のみ。マーカーを使う機能は 5〜7 の各段階で追加） |
| 5. 草・植生（立体の草、透過光と色のばらつき、季節の色、生き物と舞うもの） | **実装済み・ゲームで未確認** |
| 6. 光（光源マーカー、発光マテリアル、再帰反射、反射プローブ） | **実装済み**。発光マテリアル以外はゲームで未確認 |
| 7. 素材とオブジェクト（素材の指定、デカール、水たまりと水面、煙・湯気・霧） | **実装済み**。素材の指定以外はゲームで未確認 |

## 前提：Kino のタグとの関係

Kino はオブジェクト名の先頭のタグで物理面と当たり判定を決めます。

| タグ | 意味 |
|---|---|
| `road_` `kerb_` `gravel_` `dirt_` `grass_` `sand_` `snow_` `icyroad_` | 走行面（物理面の種類） |
| `nocol_` | 当たり判定なし |
| `alpha_` / `alphaCol_` / `alphaLit_` | 透過（なし / 当たり判定あり / 法線マップあり） |

NatureFX の指定は、**このタグを変えずに**足せるようにします。タグの直後に名前を続ける今の付け方はそのまま使えます。

- NatureFX 専用のオブジェクトは `nfx_` で始めます。メッシュを持つものは、当たり判定を付けないよう `nocol_nfx_` で始めます
- 既存のオブジェクトへの指定は、名前ではなく「プロファイル」（1 章）と「頂点カラー」（2 章）で行います

## 0. マップへの持たせ方

### 分かっていること

Kino Content SDK のマップのビルド（`Assets/Editor/Maps/MapsBuilder.cs`）は、マップのシーンを 1 つのアセットバンドルにするだけで、オブジェクトやコンポーネントを削ったり書き換えたりしません。シーンに置いたものは、空のオブジェクトも無効にしたコンポーネントも、そのままゲームに届きます。

### 原則

- **NatureFX がない環境で、描画・当たり判定・挙動が変わらないものだけを使う**
- **自作のスクリプト（MonoBehaviour）は使わない**。ゲームにそのコードがないため「スクリプトが見つからない」という警告がログに出て、中のデータも読めなくなります
- **TextAsset などを単体でバンドルに入れない**。シーンを入れたバンドルにはシーン以外を入れられない（Unity の決まり）ため、文字のデータは標準のコンポーネントに入れます

### 持たせ方

| 何を | 置き方 | NatureFX なし | NatureFX あり |
|---|---|---|---|
| マップの設定（プロファイル。1 章） | `nfx_profile` というオブジェクトに標準の **TextMesh** を付け、`text` にプロファイルの全文を入れる。MeshRenderer は無効にする | 何も描かれない | 文字列を設定として読む |
| 範囲や位置（ゾーン、水たまり、霧の範囲など。3・4 章） | **空のオブジェクト** `nfx_<種類>_<プリセット>`。Transform の位置・回転・拡大率が、箱の中心・向き・大きさ（m）になる | 何もしない | マーカーとして読む |
| 光源・反射プローブ・デカール・局所的な霧・粒子 | HDRP / Unity の**標準のコンポーネントを無効にして**置く。オブジェクト名は `nfx_` で始める（4.3） | 無効なので何も起きない | 条件（夜など）に合わせて有効にする |
| 草木の揺れ方・空の開け具合（2 章） | 頂点カラー | HDRP/Lit は頂点カラーを使わないので変わらない | 揺れ方や積もり方に使う |
| 草を生やす範囲（5.1） | **MeshFilter だけ**（MeshRenderer なし）のオブジェクト `nocol_nfx_grass_<プリセット>` | 描画されない | 面の上に草を生やす |

- 残る副作用は、無効のまま置いたコンポーネントのテクスチャなどで、マップのファイルと読み込み時のメモリが少し増えることだけです
- これは Kino Content SDK（Unity）で作る `.knmap` の場合です。OBJ だけで作るマップには空のオブジェクトやコンポーネントを入れられないため、メッシュのマーカー（4.2）とマップ外の設定ファイル（1 章）を使います

## 1. マップごとの設定ファイル

### 置き場所

プロファイルは 2 か所に置けます。中身の書式は同じです。

| 置き場所 | 用途 |
|---|---|
| **マップの中**：`nfx_profile` オブジェクトの TextMesh の `text`（0 章） | 配布するマップ。マップと一緒に届くので、別のファイルを配る必要がない |
| **マップの外**：`kino/config/NatureFX/maps/<シーン名>.nfx` | 公式のコースや OBJ のマップ、作者の手元での調整 |

- 両方ある場合は、**マップの外のファイルを優先**し、マップの中のプロファイルは使いません（丸ごと置き換え）
- `<シーン名>` は、そのマップを読み込んだときのシーン名です。F8 の **Map** タブ に表示されます
- マップの中のプロファイルは、NatureFX の F8 から「マップの外のファイルとして書き出す」ことができるようにします（手元で調整して、またマップに戻すため）

### 書式

INI に近い形式です。行頭または空白の直後の `#` から行末まではコメントです（正規表現の中の `#` は、直前に空白がなければそのまま使えます）。

F8 の **Map** タブ で、読み込まれているシーン名の確認、ひな形の作成（**Create template**）、編集後の読み直し（**Reload map profile**）ができます。

```ini
# Sample Touge 用
[map]
name = Sample Touge
inheritGlobalRules = true      # true: このファイルのルールの後に既定のルールも使う
vertexColors = true            # 2. の頂点カラーを使う（false なら頂点カラーを無視）
foliageWind = true             # 画面の葉を風で揺らす（幹が葉と別のメッシュのマップだけ。既定 false: 影だけ揺れる）

[rules]
# 既定の rules.txt と同じ書式。上から順に判定し、最初に当てはまったものを使う
(?i)^HDRP/Lit$ | (^|/)alpha_trees_ => NatureFX/Foliage
(?i)^HDRP/Lit$ | (^|/)alpha_grass_ => NatureFX/Foliage
(?i)^HDRP/Lit$ | (^|/)road_ => NatureFX/LitAccumulation

[defaults]
# マップを読み込んだときの初期値。利用者がメニューで変えた値は上書きしない
wind.direction = 135           # 度。0 = +Z（北）、時計回り
wind.strength = 0.5            # 0..2
wind.gust = 0.4                # 0..1
season = autumn                # none / spring / summer / autumn / winter（下の表）
snow = 0.0                     # 0..1
leaves = 0.4
dust = 0.1
wetness = 0.0
fog.distance = 1200            # m。0 でフォグを足さない
fog.height = 80                # m

[zone.summit]
# 3. の天候ゾーン（nfx_zone_summit）の中での値
snow = 0.6
fog.distance = 300
wind.strength = 1.2
blend = 40                     # m。ゾーンの縁からこの距離で外の値となめらかにつなぐ
priority = 10                  # ゾーンが重なったときは大きいほうを使う
```

### `season` の意味

`season` は `[defaults]` の蓄積値をまとめて決める近道です。個別の値（`snow` など）を書いた場合はそちらを優先します。

| season | snow | leaves | dust | wetness |
|---|---|---|---|---|
| `spring` | 0 | 0.1 | 0.1 | 0.2 |
| `summer` | 0 | 0 | 0.3 | 0 |
| `autumn` | 0 | 0.5 | 0.15 | 0.1 |
| `winter` | 0.5 | 0.1 | 0 | 0.3 |

### 利用者の設定との優先順位

- 「利用者が変えた値」は、マップを読み込んだ時点からスライダーを動かした値です。動かしたキーは、次のマップを読み込むまで利用者の値を使います
- NatureFX は設定ファイル（利用者の設定）を書き換えません。別のマップに移る、または「Use map profiles」をオフにすると、利用者の値がそのまま戻ります
- 天候のプリセット（Manual 以外）を選ぶと、蓄積の値（snow など）はプリセットのものになります。風の強さ・向きと霧はプリセットの上からも効きます
- `fog.distance` は霧の減衰距離（HDRP の Fog の Attenuation Distance）、`fog.height` はカメラの高さから霧が薄れていく高さです（峠のどの標高でも車のまわりに霧が残るよう、霧の底はカメラの高さに合わせてゆっくり動きます）。雨や霧の天候では距離が短くなります

1. 利用者がメニューで変えた値（最優先）
2. 天候ゾーンの値（ゾーンの中にいるとき）
3. マップの設定ファイルの `[defaults]`
4. NatureFX の既定値

メニューに「マップの設定を使う」スイッチを設け、オフにすると 2 と 3 を無視します。

## 2. 頂点カラーによる指定

メッシュの頂点カラーに、揺れ方と雪の積もり方を書き込みます。`[map] vertexColors = true` のマップでだけ使います（頂点カラーのないメッシュは白 (1,1,1,1) として読まれ、「全体が最大に揺れる」誤った見た目になるため）。

| チャンネル | 使い道 | 0 | 1 |
|---|---|---|---|
| **R** | 風の影響の強さ（`NFX_Wind` の `Weight`） | 揺れない（根元・幹） | 最大に揺れる（枝先・葉先・草の先） |
| **G** | 揺れの位相のずらし | — | — （0..1 を 0..2π に変換。隣り合う株が同じ動きをしないように乱数を入れる） |
| **B** | 硬さ（`NFX_Wind` の `Stiffness`） | 草のように柔らかい | 動かない |
| **A** | 空の開け具合（`NFX_Accumulation` の `Exposure`） | 屋根の下・橋の下・トンネル | 空が完全に開けている |

### 付け方の目安

- **木**：R は高さに比例（地面 0、樹冠の上 1）、幹は R = 0・B = 0.8 前後
- **草の株・ササ**：R は株の根元 0、先端 1。G は株ごとに乱数
- **路面・地形**：R = 0。A は森の中や崖の下で下げると、雪や落ち葉が自然にまばらになる
- **橋の下・トンネル**：A = 0 にすると雪・落ち葉・濡れが付かない

### 注意：OBJ 形式の KN マップ

OBJ には頂点カラーの標準的な書き方がありません（`v x y z r g b` は一部のソフトだけの拡張で、アルファもありません）。
頂点カラーは **Kino Content SDK で作る `.knmap`** でだけ使える前提とします。OBJ 形式のマップでは `vertexColors = false` にして、名前のルールだけを使ってください。

### map generator での自動書き込み（案）

| 対象 | R | G | B | A |
|---|---|---|---|---|
| `trees_*`（枝葉のカード） | 高さ ÷ 樹高 | 木ごとの乱数 | 0 | 林の密度から（密な所ほど低く） |
| `trees_bark` | 0 | 0 | 0.8 | 1 |
| `grass*` `sasa` `shrubs` | 株の中の高さ ÷ 株の高さ | 株ごとの乱数 | 0 | 1 |
| 路面・地形 | 0 | 0 | 1 | 上空の木の被さり具合（1 − 樹冠の被覆率） |

## 3. 天候ゾーンのマーカー

マップの一部だけ天候を変えるための、見えない箱です。

### 名前

```
nfx_zone_<id>
```

- `<id>` は英数字と `-` だけ。プロファイルの `[zone.<id>]` と対応します
- 空のオブジェクトで置き、Transform の拡大率で箱の大きさ（m）を決めます。回転させた箱もそのまま判定します
- OBJ のマップでは、直方体のメッシュ `nocol_nfx_zone_<id>` で置けます（4.2）

### 中で変えられる値

`[zone.<id>]` には `[defaults]` と同じキーに加えて、次を書けます。

| キー | 意味 | 既定 |
|---|---|---|
| `blend` | 縁から外の値へなめらかにつなぐ距離（m） | 20 |
| `priority` | ゾーンが重なったときの優先度（大きいほうを使う） | 0 |

判定はカメラの位置で行います。カメラがゾーンの中に入ると、`blend` の距離をかけてゾーンの値に近づきます。

### 例

- 峠の頂上付近だけ雪：`nfx_zone_summit` を頂上に置き、`snow = 0.6`
- 谷沿いだけ霧：`nfx_zone_valley` を谷に沿って置き、`fog.distance = 250`
- トンネルの中だけ風を止める：`nfx_zone_tunnel` を置き、`wind.strength = 0`

### 将来の拡張（検討中）

- `nfx_shelter_<id>`：箱の中を「屋根の下」として扱い、雪・落ち葉・濡れを付けない（頂点カラーの A を塗れないマップ向け）。シェーダー側に箱の一覧を渡す必要があるため、数に上限を設ける（8 個程度）
- `nfx_wind_<id>`：局所的な風（谷を吹き上がる風など）の向きと強さ

## 4. マーカーの共通書式

5〜7 章の「置くもの」は、マーカーで指定します。マーカーの置き方は 4 通りあり、どれも同じものとして読みます。

| 置き方 | 使える所 | 位置・大きさ・向き |
|---|---|---|
| 4.1 空のオブジェクト | SDK のマップ（推奨） | Transform の位置・拡大率・回転 |
| 4.2 メッシュのマーカー | OBJ のマップ | メッシュの境界の箱。向きは名前のキー |
| 4.3 無効にした標準のコンポーネント | SDK のマップ | Transform と、コンポーネント自身の設定 |
| 4.4 プロファイルの `[markers]` | どこでも（公式のコースなど） | 座標とキー |

### 名前

```
nfx_<種類>_<プリセット>[__<キー>-<値>]...
```

- 例：`nfx_light_sodium`、`nfx_puddle`、`nfx_volume_mist__density-0p5`
- `<種類>` は `zone` `light` `probe` `grass` `fx` `decal` `puddle` `water` `volume` `forest` のどれか
- `__<キー>-<値>` で、プリセットの値を一部だけ変えられます。小数は `0p5`（= 0.5）、負の数は `m30`（= −30）と書きます。Blender や Unity が付ける `.001` や ` (1)` のような番号は無視します
- メッシュを持つマーカーは `nocol_` を前に付けます（`nocol_nfx_...`）。Kino が当たり判定を付けないようにするためです

### 4.1 空のオブジェクト

- 位置は Transform の位置、箱の大きさは拡大率（m）、向きは回転です（光やデカールは、オブジェクトの前（+Z）の向き）
- 何も描かず、当たり判定もないので、NatureFX がない環境に影響しません

### 4.2 メッシュのマーカー（OBJ のマップ向け）

- `nocol_nfx_<種類>_...` という名前の直方体のメッシュを置きます。位置と大きさはメッシュの境界の箱です
- 向きは名前のキー `yaw`（0 = +Z（北）、時計回り。風向きと同じ）と `pitch`（0 = 水平、90 = 真下）で指定します
- NatureFX がない環境では見えてしまうため、マテリアルは透明（アルファ 0）にしておきます。NatureFX は読み込み時に描画を止めます

### 4.3 無効にした標準のコンポーネント

HDRP / Unity の標準のコンポーネントを付けたオブジェクトを、`nfx_` で始まる名前で置き、**コンポーネント（またはオブジェクト）を無効にしておきます**。NatureFX が条件に合わせて有効にします。明るさや色、テクスチャなどは、Unity のエディターでそのコンポーネントに設定した値をそのまま使います。

| 種類 | コンポーネント | NatureFX がすること |
|---|---|---|
| `light` | Light（HDRP の光源） | `when` に合わせて点灯・消灯、ちらつき、影付きの数の管理（6.1） |
| `probe` | Reflection Probe | 時刻・天候の変化に合わせて描き直す（6.4） |
| `decal` | Decal Projector | 有効にする。`leaves_pile` などは量に合わせて濃さを変える（7.2） |
| `volume` | Local Volumetric Fog | 条件に合わせて有効にし、濃さを変える（7.4） |
| `fx` | Particle System | 条件に合わせて再生・停止する（5.4） |

- 名前のプリセットは省略できます（`nfx_light`）。その場合は、点灯の条件など NatureFX 側の動きだけをキーで決めます（`nfx_light__when-dusk`）
- プリセットを書いた場合（`nfx_light_sodium`）は、コンポーネントがなければ NatureFX がプリセットの光源を作り、あればコンポーネントの値を優先します

### 4.4 プロファイルでの配置

マップを編集できない場合（公式のコースなど）のために、同じものをプロファイルの `[markers]` に座標で書けます。

```ini
[markers]
# 種類_プリセット = x, y, z [, キー=値 ...]   （ワールド座標、m）
light_sodium    = 120.5, 34.0, -88.2, yaw=90, pitch=70
volume_mist     = 300, 10, 450, size=80x20x200
puddle          = 41.0, 12.3, 5.5, size=4x0.3x2
```

公式のコースで光源の位置を探すため、F8 の **Tools** に「カメラの位置をコピー」を設けます。

### 数の上限

| 種類 | 上限 | 超えた場合 |
|---|---|---|
| `light` | 描画は 64 個（影付きは 8 個） | カメラに近い順 |
| `probe` | 16 個 | カメラに近い順に更新 |
| `decal` | 512 個 | 距離で間引く |
| `fx` `volume` | 32 個 | 距離で止める |

## 5. 草・植生

### 5.1 立体の草

NatureFX が地面の上に草の葉を GPU で大量に描きます。板の草（`alpha_grass`）では出ない、密度と立体感を出すためのものです。

**生やす場所**
- `nocol_nfx_grass_<プリセット>` のメッシュの面の上（草を生やす範囲の地面のコピーを、**MeshFilter だけ**で置く。MeshRenderer がないので NatureFX がない環境では描画されない）
- `[grass] auto = true` のとき、`grass_` で始まる走行面にも自動で生やす

**プリセット**

| プリセット | 見た目 | 高さ |
|---|---|---|
| `lawn` | 刈り込まれた芝 | 5〜10cm |
| `wild` | 路肩の雑草（季節で枯れる） | 20〜50cm |
| `susuki` | ススキ（秋に穂が出る） | 80〜150cm |
| `sasa` | ササ（冬も緑） | 40〜80cm |
| `moss` | 苔（湿った日陰で濃くなる） | 1〜2cm |

キー：`density`（本/m²）、`height`（倍率）、`hue`（色相のずらし、度）

**動き**
- 風で揺れる（風の向き・強さ・突風をそのまま使う）
- タイヤが通ると倒れ、しばらくで起き上がる（タイヤ跡マップの圧縮を使う）
- 雪が積もると埋もれる。雪の深さより低い草は描かない

**負荷**：カメラから 60m まで。遠くは本数を減らし、地面の色になじませます。F8 で密度と距離を変えられます。

**実装メモ**
- 8m 四方の区画ごとに草のメッシュを作り、カメラが近づいたら作って離れたら捨てます。遠い区画は葉の 1/4 か 1/2 だけを描きます
- 描画は `NatureFX/Foliage`（HDRP の光と影が付く）なので、F8 の Replace shaders（シェーダーの作り直し）がオンのときだけ出ます
- 生やす面のメッシュは「読み取り可能」である必要があります。`[grass] auto = true`（`preset` で種類）は静的バッチされていない `grass_` の面だけに効きます
- 草はレイトレーシングの影を落としません（HDRP の影は 25m まで）

### 5.2 葉の透過光と色のばらつき

`[foliage]` に、木の種類ごとの見え方を書きます。左辺は `[rules]` と同じ判定の書式です。

```ini
[foliage]
(?i)alpha_trees_cedar   => type=conifer,   translucency=0.3, variation=0.15
(?i)alpha_trees_broad   => type=deciduous, translucency=0.7, variation=0.3, autumn=red
(?i)alpha_trees_ginkgo  => type=deciduous, translucency=0.6, autumn=yellow
(?i)alpha_sasa          => type=bamboo
```

| キー | 意味 |
|---|---|
| `translucency` | 逆光のとき、葉が透けて明るく見える強さ（0..1） |
| `variation` | 木ごとの色のずらし（0..1）。木の位置から乱数を作るので、データは要らない |
| `type` | `conifer`（針葉樹）/ `deciduous`（広葉樹）/ `bamboo`（竹・ササ）/ `grass` |
| `autumn` | 広葉樹の紅葉の色：`red` / `yellow` / `mixed`（既定）/ `brown` |

### 5.3 季節の色

季節（メニュー、天候、マップの `[defaults] season`）によって、`type` ごとに色を変えます。

| type | 春 | 夏 | 秋 | 冬 |
|---|---|---|---|---|
| `deciduous` | 明るい若葉 | 濃い緑 | `autumn` の色 | 葉を落とす（枝だけになる） |
| `conifer` | 緑 | 緑 | 少し褐色寄り | 暗い緑 |
| `bamboo` | 緑 | 緑 | 緑 | 葉の縁が白く枯れる（隈笹） |
| `grass` | 明るい緑 | 緑 | 黄土色に枯れる | 枯れ草 |

冬の広葉樹は、葉の透過の切り抜きを強めて葉を減らします。季節の移り変わりの途中では、木ごとに少しずつずらして変えます。

- 季節は F8 > Weather > Season で選びます。Auto は、天候の Autumn・Snow ならその季節、それ以外はマップの `[defaults] season`。どれもなければ色を変えません
- 季節を変えると、約 30 秒で次の季節へ進みます（木ごとにずれる）
- `[foliage]` に当てはまった `HDRP/Lit` のマテリアルは `NatureFX/Foliage` に切り替わります
- 透過光は「逆光のとき法線を太陽側へ傾けて明るくする」近似です。冬に落とした葉も、レイトレーシングの影には残ります

### 5.5 遠景の森

- `nocol_nfx_forest_<conifer|broadleaf|mixed>` のメッシュ（MeshFilter だけ）の面に、木を十字の板（インポスター）で 2km 先まで並べます。マップで作っていない山肌を埋めるためのものです
- キー：`density`（100m² あたりの本数、既定 2）、`height`（m）
- 風で揺れ、季節の色・冬の落葉も付きます。遠くは本数を減らし、影は 200m まで

### 5.4 生き物と舞うもの

`nfx_fx_<プリセット>` の箱の中に、細かい粒を出します。条件（季節・時刻・天候）に合うときだけ出ます。自分で作った Particle System を無効にして `nfx_fx` という名前で置くこともできます（4.3）。

| プリセット | 出るもの | 条件 |
|---|---|---|
| `fireflies` | ホタル | 夏の夜、雨でないとき |
| `leaves` | 舞い落ちる葉 | 秋。風が強いほど多い |
| `petals` | 桜の花びら | 春 |
| `moths` | 灯りに集まる虫 | 夏の夜。光源マーカーの近くに自動で付く |
| `dust` | 日差しの中の塵 | 晴れの日中 |
| `pollen` | 綿毛・花粉 | 春〜初夏 |

キー：`amount`（倍率）

- 動かすのはカメラに近い 32 個まで、80m より遠いものは止めます。季節を決めていない（None）ときは、季節に縛られないもの（夏の夜のホタルと虫、落ち葉が多いときの落ち葉、塵）だけ出ます

## 6. 光

### 6.1 光源マーカー

`nfx_light_<プリセット>` の位置に HDRP の光源を置きます。Unity のエディターで無効にした Light を置けば、その明るさ・色・形のまま、NatureFX が点灯を管理します（4.3）。

| プリセット | 種類 | 色温度 | 明るさ | 既定の向き |
|---|---|---|---|---|
| `sodium` | 高圧ナトリウム灯（橙色の街灯） | 2000K | 12000 lm | 真下 |
| `mercury` | 水銀灯（古い青白い街灯） | 4200K | 10000 lm | 真下 |
| `led_street` | LED の街灯 | 4500K | 9000 lm | 真下 |
| `tunnel` | トンネル照明（橙） | 2000K | 4000 lm | 真下 |
| `vending` | 自動販売機の前面 | 6000K | 1500 lm（面光源） | `yaw` の向き |
| `floodlight` | 投光器（駐車場など） | 5000K | 30000 lm | `yaw`・`pitch` |
| `beacon` | 黄色の回転灯・点滅灯 | 黄 | 800 lm | 全方向 |
| `lantern` | 提灯・常夜灯 | 2200K | 300 lm | 全方向 |

キー：`lm`（明るさ）、`k`（色温度）、`range`（届く距離 m）、`yaw` `pitch`、`spot`（スポットの角度）、`shadow`（`on` / `off`）、`flicker`（0..1。古い蛍光灯のちらつき）、`when`（`night`（既定）/ `dusk`（夕方から）/ `always`）

- 点灯は太陽の高さで決めます。街灯ごとに数秒ずらして、一斉に点かないようにします
- 霧や雨の夜には光の筋（ボリューム光）が見えます。強さは F8 で変えられます
- 光源の器具のモデルはマップ側で置いてください（マーカーは光だけです）
- 向き：`yaw` `pitch` を書けばそれを、書かなければ空のオブジェクトの回転を、回転していなければプリセットの向き（街灯は真下）を使います
- `vending` は面光源の代わりに前へ向けた広いスポットです（面光源はレイトレーシングのランプに含まれないため）
- 夕方からの点灯は太陽の高さ 6〜10°、夜の点灯は −1〜3°（街灯ごとにずれる）。ナトリウム灯・水銀灯は数秒かけて明るくなります
- F8 > Map タブの Lights に、点いている数・描いている数・影付きの数が出ます

### 6.2 発光マテリアル

`[emissive]` で、マテリアルを夜だけ光らせます。

```ini
[emissive]
(?i)led_sign       => nits=800,  k=6500, when=always
(?i)window_house   => nits=60,   k=2700, when=night, random=0.6
(?i)vending_front  => nits=400,  k=6000, when=always
```

| キー | 意味 |
|---|---|
| `nits` | 明るさ（cd/m²）。現実の単位なので、露出と自然に合う |
| `k` | 色温度 |
| `when` | `night` / `dusk` / `always` |
| `random` | 点いている割合（0..1）。家の窓などをオブジェクトごとに点けたり消したりする |
| `flicker` | ちらつき（0..1） |

光らせる範囲は、マテリアルの色テクスチャの明るい所です（`mask=alpha` でテクスチャのアルファ、`mask=full` で面全体）。

- `random` と点灯のずれは、ワールド座標の 6m 四方の区画ごとに決まります（Kino のマップは静的バッチでオブジェクトがまとめられ、オブジェクト単位で区別できないため）
- `[emissive]` や `[materials]` に当てはまった `HDRP/Lit` のマテリアルは、置き換えルールがなくても NatureFX のシェーダーに切り替わります（雪や濡れも付くようになります）

### 6.3 再帰反射

白線・標識・デリネーター（視線誘導標）・ガードレールの反射板が、ヘッドライトの光を来た方向へ返して光って見えるようにします。夜の峠らしさに一番効く要素です。

`[materials]`（7.1）で `retro` を付けます。

```ini
[materials]
(?i)markings        => asphalt_paint, retro=0.6
(?i)warning_sign    => metal_painted, retro=1.0
(?i)delineator      => plastic, retro=1.0
```

- 光るのは、ヘッドライトとカメラが近いときだけです（遠くの車の光は返らない）
- 雨で白線が水に覆われると、反射が弱まります（現実と同じ）
- `retro = 1` は標識の反射シート（約 300 cd/lx/m²）、`0.6` は白線程度（約 5）です。カメラとヘッドライトの角度で返る量が決まるので、運転席の視点では強く、車の後ろの高い視点では弱く光ります
- 対象はカメラに近い 4 台分のヘッドライトです

### 6.4 反射プローブ

車体や濡れた路面に映り込む景色を、その場所に合ったものにします。今は空の映り込みしかないため、森の中やトンネルでも車体に青空が映ります。

- `nfx_probe` を、映り込みが変わる所（森の中、トンネル、開けた所）に置きます。空のオブジェクトなら箱の大きさが影響範囲、無効にした Reflection Probe ならその影響範囲の設定を使います（4.3）
- `[probes] auto = true` なら、道路に沿って `spacing`（既定 60m）ごとに自動で置きます
- 時刻・天候が変わったら、カメラに近いものから 1 フレームに 1 面ずつ描き直します
- 自動の配置は「車が走った所」に置きます（道路の形はマップから分からないため）。`spacing` の範囲にプローブがなければ車の位置に置き、16 個を超えたら一番遠い自動のプローブを外します
- 空のオブジェクトの大きさが 2m 以下なら、影響範囲は 60×30×60m になります

### 6.5 夜の背景

```ini
[night]
skyline = 180      # 街明かりの方角（度。0 = +Z、時計回り）
distance = 3000    # m
spread = 70        # 広がる角度
height = -150      # カメラからの高さ（m。麓の街なら負）
lights = 900       # 灯りの数
stars = true       # 星（既定 true）
```

- 星は、トラックの空が HDRP の Physically Based Sky のときだけ出ます（宇宙の発光に星空を入れる）。雲が多いと隠れます
- 街明かりは夜にだけ点きます（光の点だけ。街の上の空の明るさはまだありません）

### 6.6 空と雲

- 雲は HDRP のボリュームの雲で、天候の雲量に合わせて増え、山に影が流れます（F8 > Weather > Sky）
- 雲海：`[clouds] sea = <高さ m>` で、朝と雨上がりに雲の層がその高さ（上面）まで下りてきます。峠の上から谷を見下ろす絵になります
- 遠くの山が青く霞みます（Distant haze）。マップの霧（`fog.distance`）がある所ではそちらを使います

### 6.7 街灯の配光

- `sodium` `mercury` `led_street` は道路に沿って細長く広がる配光（バットウィング）、`tunnel` は広く均一、`floodlight` は中心が強い配光です。道路の向きは光源の x 軸（`yaw` で回す）です。`ies=off` で配光なし
- レイトレーシングのランプの影（Ray traced shadows for every lamp）がオンなら、街灯の影はすべてレイトレーシングで付き、「影付き 8 灯」の制限はなくなります。ランプはカメラに近い 128 灯まで、1 画素あたり 8 候補から選んで影を付けます（ReSTIR の最初の段階。フレーム間・隣の画素での再利用は未実装）

## 7. 素材とオブジェクト

### 7.1 素材の指定

`[materials]` で、マテリアルに現実の素材を割り当てます。素材ごとに、濡れ方・汚れ方・経年変化が変わります。

```ini
[materials]
(?i)road_asphalt     => asphalt_old
(?i)masonry          => masonry, moss=0.6
(?i)guardrail        => metal_galvanized, rust=0.2
(?i)concrete         => concrete, stain=0.4
(?i)rock             => rock, moss=0.3
```

| 素材 | 濡れたとき | 経年変化（キー） |
|---|---|---|
| `asphalt_old` / `asphalt_new` | 暗くなり、水たまりができる。新しいほど黒く粒が細かい | `wear`（ひび・白っぽさ） |
| `asphalt_paint` | 滑らかに光る | `wear`（かすれ） |
| `concrete` | 濃い灰色にしみる | `stain`（雨だれの黒い筋） |
| `masonry` / `rock` | 継ぎ目から先に濡れる | `moss`（日陰・上向きの面に苔） |
| `metal_galvanized` / `metal_painted` | 水滴が玉になる | `rust`（錆。縁と下側から） |
| `glass` | 水滴が流れ落ちる | `dirt` |
| `plastic` / `wood` / `soil` | それぞれの吸水の度合い | `dirt` |

### 7.2 デカール

`nfx_decal_<プリセット>` の箱の中の地面に、上から模様を描きます。ゲームの HDRP 設定ではデカールが無効なので、NatureFX のシェーダーが描きます（NatureFX のシェーダーの面にだけ出ます）。無効にした Decal Projector を `nfx_decal` という名前で置くこともできますが、ゲームがデカールを有効にしない限り表示されません（4.3）。

| プリセット | 模様 |
|---|---|
| `crack` | 路面のひび割れ |
| `patch` | 補修跡（色の違うアスファルトの継ぎはぎ） |
| `oil` | 油染み（雨のとき虹色に光る） |
| `leaves_pile` | 落ち葉の吹き溜まり（落ち葉の量に合わせて増える） |
| `sand` | 砂・砂利の散らばり |
| `skid` | 古いブラックマーク（ブレーキ跡） |
| `moss_edge` | 路肩の苔・土の汚れ |
| `slow_dots` | 減速を促す破線（車線を横切るブロックの列） |
| `zebra` | ゼブラ（導流帯：枠と斜線） |
| `speed_30` / `speed_40` / `speed_50` | 路面の速度表示（+z の側から読める向き） |
| `joint` | 橋・伸縮の継ぎ目 |
| `manhole` | マンホールの蓋 |
| `worn_line` | かすれた白線 |

キー：`yaw`、`opacity`、`seed`（模様の選び方）

- 模様は NatureFX が描いた 128px の画像です。空のオブジェクトの拡大率が大きさ（x：幅、z：長さ、y：上下に届く範囲）、Y 軸の回転（または `yaw`）が向きです
- 描くのはカメラに近い 32 個まで。雪や落ち葉はデカールの上に積もります
- 油染みは濡れると虹色に光ります

### 7.3 水たまりと水面

- `nfx_puddle`：雨で水がたまる所。箱の中の低い所から水が広がり、雨の強さで大きくなります。雨がやむと、時間をかけて小さくなります。雨粒の波紋と映り込みも付きます
- `nocol_nfx_water_<プリセット>`：常に水がある所。水面の形のメッシュを **MeshFilter だけ**で置きます（NatureFX がない環境では描画されない）

| プリセット | 水面 |
|---|---|
| `stream` | 沢・小川。`yaw` の向きに流れる |
| `gutter` | 側溝。雨の量で水位が上がり、流れが速くなる |
| `pond` | 池。風でさざ波が立つ |

- 水たまりの箱は、中央から水がたまります。強い雨で約 1 分半で満ち、やむと 10 分ほどかけて引きます。カメラに近い 16 個まで
- 水たまりは NatureFX のシェーダー（`NatureFX/LitAccumulation` など）の面にだけ出ます
- 水面は不透明の暗い面です（映り込みで水に見せる）。側溝は雨で水位が上がります（キー `rise`、既定 0.08m）

### 7.5 法面と崖（[terrain]）

```ini
[terrain]
(?i)cliff_|slope_ => triplanar, tile=4, steep=rock_mat, flat=grass_mat, slope=0.55, blend=0.15, noise=0.5, maptile=4
```

| キー | 意味 |
|---|---|
| `triplanar` | 色テクスチャを 3 方向から貼る（急な面で縦に伸びない） |
| `tile` | テクスチャ 1 枚の大きさ（m） |
| `steep` / `flat` | 急な面・平らな面に使う、マップ内のマテリアルの名前（その色テクスチャを使う）。`steep` がなければ地の色を灰色の地層模様にした岩肌 |
| `slope` `blend` `noise` | 岩肌になり始める傾き（0 平ら〜1 垂直）、境目の幅、境目の乱れ |
| `maptile` | `steep` `flat` のテクスチャ 1 枚の大きさ（m） |

- 変わるのは色だけです（法線マップはメッシュのまま）
- バンプマップ：HDRP/Lit の法線マップはそのまま使えます。視差オクルージョン（POM、`_PIXEL_DISPLACEMENT` + ハイトマップ）は NatureFX のシェーダーのバリアントにも入れました

### 7.6 冬の路面

- 寒い日（雪がある・冬）に路面が濡れて雨が止んでいると、1 分ほどかけてブラックアイス（つるつるの氷の膜）になります。晴れた昼は薄くなります
- 雪の日は、車が走った所の脇に雪が押しのけられて積もります（タイヤ跡マップから。轍は前から実装済み）

### 7.7 カーブミラー

- 鏡の面のマテリアルに `[materials]` で `mirror` を付けます（完全な金属の鏡になる）。映る景色はレイトレーシングの反射なので、Ray traced reflections が必要です

### 7.4 煙・湯気・霧の源

`nfx_volume_<プリセット>` の箱の中に、局所的な霧を置きます（HDRP の Local Volumetric Fog に動くノイズを貼る）。自分で設定した Local Volumetric Fog を無効にして `nfx_volume` という名前で置くこともできます（4.3）。

| プリセット | 見た目 | 条件 |
|---|---|---|
| `mist` | 谷を這う霧 | 早朝、雨上がり |
| `steam` | マンホール・側溝の湯気 | 寒い日 |
| `smoke` | 煙突・焚き火の煙 | `when` で指定 |
| `road_steam` | 雨上がりの路面から立つ湯気 | 雨がやんだ直後の晴れ間（自動） |
| `haze` | 遠くの霞 | 晴れた日中 |

キー：`density`、`when`（`always` / `night` / `dusk` / `day`）、`yaw`（煙が流れる向き。既定は風向き）

- 局所的な霧は HDRP のボリューメトリックフォグがオンのときだけ描かれます。表示中は NatureFX がフォグのボリュームでボリューメトリックをオンにします（ゲームのフレーム設定で無効なら出ません）
- 条件が合うと 8 秒ほどかけて濃くなり、外れると薄れて消えます。カメラに近い 32 個まで

## 8. map generator での自動書き込み（案）

map generator の設定（`config/<name>.yaml`）と生成物から、NatureFX 用のデータを自動で作ります。

- map generator（Python）は、プロファイルの本文と、マーカー・光源などの一覧（位置・向き・大きさ・種類）を JSON で書き出します
- Unity でシーンを組み立てる `MapBuilder.cs` が、その JSON から `nfx_profile`（TextMesh）、空のオブジェクト、無効にした Light などを置き、メッシュに頂点カラーを書き込みます
- 手作業は要らず、作ったマップを NatureFX なしで読み込んでも見た目は変わりません

| map generator の要素 | NatureFX への書き出し |
|---|---|
| `markings` | `[materials]` `asphalt_paint, retro=0.6` |
| `guardrail` | `metal_galvanized, rust=0.15`。反射板（`delineator`）に `retro=1.0` |
| `warning_sign` / `route_sign` | `metal_painted, retro=1.0` |
| `led_sign` | `[emissive]` `nits=800, when=always` |
| `masonry` / `rubble` / `rock` | `masonry` / `rock`、`moss` は林の中ほど高く |
| `trees`（暗い緑 / 明るい緑） | `[foliage]` `conifer` / `deciduous` |
| `grass` / `sasa` / `shrubs` | `[foliage]` `grass` / `bamboo`。路肩の地面に `nocol_nfx_grass_wild`（MeshFilter だけ） |
| 道路の縦断の低い所・待避所 | `nfx_puddle`（空のオブジェクト） |
| 側溝 | `nocol_nfx_water_gutter`（MeshFilter だけ） |
| 林に囲まれた区間・開けた区間の境目 | `nfx_probe`（無効にした Reflection Probe） |
| 谷側の低い所 | `nfx_volume_mist`（空のオブジェクト） |
| 電柱・待避所の照明（設定にあれば） | `nfx_light_sodium` などの無効にした Light |

## 9. 実装の順番（案）

| 段階 | 内容 | 理由 |
|---|---|---|
| 1 | マップの設定ファイル、マーカーの読み取り、`[materials]` と `[emissive]` | 他のすべての土台。素材の指定だけでも見た目が大きく変わる |
| 2 | 光源マーカー、再帰反射、反射プローブ | 夜の見た目が最も変わる |
| 3 | 葉の透過光・色のばらつき、季節の色 | 既存の Foliage シェーダーへの追加で済む |
| 4 | 立体の草 | 新しい描画（GPU インスタンシング）が必要で、負荷の調整も要る |
| 5 | デカール、水たまりと水面、煙・湯気・霧、生き物と舞うもの | それぞれ独立していて、後から足せる |

**確認が必要なこと**
- デカールと Local Volumetric Fog は、ゲームの HDRP 設定で有効になっている必要があります。段階 5 の前にゲームのフレーム設定を調べます
- Kino の knmap は、シーンを削らずにそのままバンドルにします（0 章）。空のオブジェクトや無効にしたコンポーネントが実際にゲームで読めることは、テスト用のマップで確かめます

## 実装メモ（NatureFX 側）

| 項目 | 場所（予定） |
|---|---|
| 設定ファイルの読み込み | `Map/MapProfile.cs`。シーン読み込み後の再スキャン（`NatureFXMod.RescanAfterDelay`）で読む。マップの中の `nfx_profile` の TextMesh も読むよう拡張する（マップの外のファイルを優先） |
| ルールの合成 | `MaterialReplacer.LoadRules` にマップのルールを先頭に足す処理を追加 |
| 頂点カラー | シェーダーにマテリアルの値 `_NFX_UseVertexColor` を足し、差し替え時に設定する |
| ゾーン | `Map/WeatherZones.cs`（新規）。`zone` のマーカーを集め、毎フレームのカメラ位置から値を合成して `AccumulationController` と `WindController` に渡す |
| マーカー | `Map/MarkerScanner.cs`。今は `nocol_nfx_` のメッシュと `[markers]` を読む。空のオブジェクト（`nfx_`、Transform の位置・回転・拡大率）と、無効にしたコンポーネントを持つオブジェクトも読むよう拡張する（`FindObjectsInactive.Include` で無効のものも探す） |
| 素材・発光 | `Map/MaterialProfiles.cs`。差し替え時にマテリアルの値（`_NFX_Material`、`_NFX_Emission` など）を設定する |
| 光源 | `Map/MapLights.cs`（新規）。無効にした Light はそのまま使い、プリセットだけのマーカーには HDAdditionalLightData を作る。太陽の高さで点灯、距離で間引く |
| 再帰反射 | ヘッドライトの位置と向きを `HeadlightController` からグローバル配列で渡し、シェーダーで光を返す |
| 反射プローブ | `Map/MapProbes.cs`（新規）。HDAdditionalReflectionData（OnDemand）を順番に描き直す |
| 立体の草 | `Nature/GrassRenderer.cs`（新規）と `NFX_Grass.shader`。`Graphics.RenderMeshIndirect` |
