# NatureFX マップ作者向け仕様

本書は、KN マップの作者がマップの見せ方を NatureFX に指定するための仕様を定めます。
指定がない場合、NatureFX はシェーダー名とオブジェクト名の規則からマップの内容を推定して処理します。本書の指定を使うと、推定ではなくマップ側の指定によって見た目を決定できます。

指定はすべてマップのデータ自体に格納できます。NatureFX を導入していない環境では、表示や動作は変わりません（0 章）。

## はじめに

- 0〜7 章の内容はすべて実装済みです。未実装の項目には「（予定）」と記載しています。予定の詳細は [ROADMAP.md](ROADMAP.md)、ゲーム内での確認状況は [HANDOFF.md](HANDOFF.md) を参照してください。
- F8 の「Map」タブでは、読み込んだプロファイル、マーカーの数、各機能の状態（実行中の処理と待機中の条件）を確認できます。「Show markers」をオンにすると、マーカーの箱と光源を画面に重ねて表示します。
- マップの指定は、F8 > Map の「Use map profiles」（既定オン）がオンの場合にだけ適用します。
- 素材、発光、草木の色、3D の草、藪は NatureFX のシェーダーで描画します。このため、F8 の「Replace shaders」（シェーダーの作り直し）もオンにする必要があります。
- デカール、水たまりと水面、局所的な霧、粒子は、F8 > Map の「Map effects」（既定オン）で切り替えます。

## 前提 Kino のタグとの関係

Kino は、オブジェクト名の先頭に付けたタグによって物理面と当たり判定を決定します。

| タグ | 意味 |
|---|---|
| `road_` `kerb_` `gravel_` `dirt_` `grass_` `sand_` `snow_` `icyroad_` | 走行面（物理面の種類） |
| `nocol_` | 当たり判定なし |
| `alpha_` / `alphaCol_` / `alphaLit_` | 透過（なし / 当たり判定あり / 法線マップあり） |

NatureFX の指定は、これらのタグを変更せずに追加できます。タグの直後に名前を続ける現行の命名方法は、そのまま使用できます。

- NatureFX 専用のオブジェクトの名前は `nfx_` で始めます。メッシュを持つオブジェクトは、当たり判定が付かないように `nocol_nfx_` で始めます。
- 既存のオブジェクトに対する指定は、名前ではなくプロファイル（1 章）と頂点カラー（2 章）で行います。
- 置き換えルール（`[rules]`）や `[materials]` などの判定は、マテリアル名とオブジェクトの階層パスの両方に適用します。

## 0. マップへのデータの格納

Kino Content SDK のマップビルド処理（`Assets/Editor/Maps/MapsBuilder.cs`）は、マップのシーンを 1 つのアセットバンドルにまとめるだけです。オブジェクトやコンポーネントの削除や書き換えは行いません。シーンに配置したものは、空のオブジェクトや無効にしたコンポーネントも含めて、そのままゲームに届きます。この動作はテストマップ `test_map` で確認済みです。

### 0.1 原則

- NatureFX がない環境で描画、当たり判定、挙動が変わらないものだけを使用します。
- 自作のスクリプト（MonoBehaviour）は使用しません。ゲームにそのコードが存在しないため、「スクリプトが見つからない」という警告がログに出力され、格納したデータも読み取れません。
- TextAsset などを単体でバンドルに含めません。Unity の仕様により、シーンを含むバンドルにはシーン以外を含められません。このため、文字データは標準のコンポーネントに格納します。

### 0.2 格納方法

| 対象 | 配置方法 | NatureFX なし | NatureFX あり |
|---|---|---|---|
| マップの設定（プロファイル、1 章） | `nfx_profile` という名前のオブジェクトに標準の TextMesh を付け、`text` にプロファイルの全文を入力する。MeshRenderer は無効にする | 何も描画されない | 文字列を設定として読み込む |
| 範囲や位置（ゾーン、水たまり、霧の範囲など、3・4 章） | 空のオブジェクト `nfx_<種類>_<プリセット>`。Transform の位置、回転、拡大率が、箱の中心、向き、大きさ（m）になる | 何もしない | マーカーとして読み込む |
| 光源、反射プローブ、デカール、局所的な霧、粒子 | HDRP / Unity の標準のコンポーネントを無効にして配置する。オブジェクト名は `nfx_` で始める（4.3） | 無効のため何も起きない | 条件（夜など）に応じて有効にする |
| 草木の揺れ方、空の開け具合（2 章） | 頂点カラー | HDRP/Lit は頂点カラーを使わないため変化しない | 揺れ方や積もり方の計算に使う |
| 草、森、藪、水面を配置する面（5・7 章） | MeshFilter だけを持ち、MeshRenderer を持たないオブジェクト `nocol_nfx_<種類>_<プリセット>` | 描画されない | 面の上に草などを生成する |

- 残る副作用は、無効のまま配置したコンポーネントのテクスチャなどにより、マップのファイルサイズと読み込み時のメモリ使用量がわずかに増えることだけです。
- 本章の方法は、Kino Content SDK（Unity）で作成する `.knmap` を対象とします。OBJ だけで作成するマップには、空のオブジェクトやコンポーネントを含められません。この場合は、メッシュのマーカー（4.2）とマップ外の設定ファイル（1 章）を使用します。

## 1. マップごとの設定ファイル（プロファイル）

### 1.1 配置場所

プロファイルは次の 2 か所に配置できます。記述形式はどちらも同じです。

| 配置場所 | 用途 |
|---|---|
| マップ内（`nfx_profile` オブジェクトの TextMesh の `text`、0 章） | 配布用のマップ。マップと一緒に配布されるため、別のファイルを配布する必要がない |
| マップ外（`kino/config/NatureFX/maps/<シーン名>.nfx`） | 公式のコース、OBJ のマップ、作者の手元での調整 |

- 両方がある場合はマップ外のファイルを優先し、マップ内のプロファイルは使用しません。マップ外のファイルが全体を置き換えます。
- `<シーン名>` は、そのマップを読み込んだときのシーン名です。コースは複数のシーンを読み込むため、ファイルが存在する最初のシーンの名前を使います。シーン名は F8 > Map に表示されます。

F8 > Map には、プロファイルを操作する次のボタンがあります。

| ボタン | 機能 |
|---|---|
| Reload map profile | 編集後のプロファイルを読み直す |
| Create template | プロファイルがない場合に、ひな形を書き出す |
| Export to file | マップ内のプロファイルを、マップ外のファイルに書き出す。手元で調整してからマップに戻す場合に使う |
| Copy camera position | 4.4 を参照 |

### 1.2 記述形式

INI に近い形式です。行頭、または空白の直後にある `#` から行末まではコメントとして扱います。正規表現の中の `#` は、直前に空白がなければそのまま使用できます。同じセクションに同じキーを 2 回記述した場合は、後の記述を使用します。未知のキーは、ログに警告を出力して無視します。

```ini
# 峠のマップの例
[map]
name = Sample Touge
inheritGlobalRules = true      # true（既定）: このファイルのルールの後に既定のルールも使う
vertexColors = true            # 2. の頂点カラーを使う（既定 false: 頂点カラーを無視）
foliageWind = true             # 画面の葉を風で揺らす（幹が葉と別のメッシュのマップだけ。既定 false: 影だけ揺れる）

[rules]
# NatureFX.rules.txt と同じ書式（<ゲームのシェーダーの正規表現> | <名前の正規表現> => <NatureFX のシェーダー>）。
# 上から順に判定し、最初に当てはまったものを使う
(?i)^HDRP/Lit$ | (^|/)alpha_trees_ => NatureFX/Foliage
(?i)^HDRP/Lit$ | (^|/)road_ => NatureFX/LitAccumulation

[defaults]
# マップを読み込んだときの初期値。利用者がメニューで変えた値は上書きしない
wind.direction = 135           # 度。0 = +Z（北）、時計回り
wind.strength = 0.5            # 0..2
wind.gust = 0.4                # 0..1
season = autumn                # none / spring / summer / autumn / winter（下の表）
snow = 0.0                     # 0..1
leaves = 0.4
dust = 0.1
wetness = 0.0
fog.distance = 1200            # m。0 でフォグを足さない
fog.height = 80                # m（既定 80）
groundblend = 0.35             # m。物体が地面の色をもらう高さ（7.8）。既定 0.35、0 で切る

[zone.summit]
# 3. の天候ゾーン（nfx_zone_summit）の中での値
snow = 0.6
fog.distance = 300
wind.strength = 1.2
blend = 40                     # m。ゾーンの縁からこの距離で外の値となめらかにつなぐ
priority = 10                  # ゾーンが重なったときは大きいほうが勝つ
```

### 1.3 セクション一覧

| セクション | 内容 | 章 |
|---|---|---|
| `[map]` | `name` `inheritGlobalRules` `vertexColors` `foliageWind` | 1・2 |
| `[rules]` | シェーダーの置き換えルール（既定のルールより先に判定する） | 1 |
| `[defaults]` | 風、季節、蓄積、霧、接地の初期値 | 1 |
| `[zone.<id>]` | 天候ゾーンの中の値 | 3 |
| `[markers]` | 座標で配置するマーカー | 4.4 |
| `[grass]` | `auto = true` で `grass_` の面にも 3D の草を生成する。種類は `preset` で指定する（既定 `wild`） | 5.1 |
| `[foliage]` | 木の種類、透過光、色のばらつき、紅葉の色 | 5.2 |
| `[emissive]` | 夜に発光するマテリアル | 6.2 |
| `[probes]` | `auto = true` で道路沿いに反射プローブを配置する。間隔は `spacing`（m、既定 60） | 6.4 |
| `[night]` | 星と遠くの街明かり | 6.5 |
| `[clouds]` | `sea = <高さ m>` で雲海 | 6.6 |
| `[materials]` | 現実の素材の割り当て、再帰反射、鏡 | 7.1 |
| `[terrain]` | 法面と崖のトリプラナー | 7.5 |
| `[paint]` | 泥はね、水しみ、轍 | 7.8 |

### 1.4 `season` の意味

`season` は、`[defaults]` の蓄積値をまとめて設定するための簡易指定です。個別の値（`snow` など）を記述した場合は、個別の値を優先します。`[defaults]` の `season` は、木と草の季節の色（5.3）にも使用します。

| season | snow | leaves | dust | wetness |
|---|---|---|---|---|
| `spring` | 0 | 0.1 | 0.1 | 0.2 |
| `summer` | 0 | 0 | 0.3 | 0 |
| `autumn` | 0 | 0.5 | 0.15 | 0.1 |
| `winter` | 0.5 | 0.1 | 0 | 0.3 |

### 1.5 利用者の設定との優先順位

値は次の順に優先します。

1. 利用者がメニューで変更した値（最優先）
2. 天候ゾーンの値（カメラがゾーンの中にある場合）
3. マップの `[defaults]`
4. NatureFX の既定値

- 利用者が変更した値とは、マップを読み込んだ後に利用者がスライダーで変更した値です。変更したキーは、次のマップを読み込むまで利用者の値を使用します。スライダーのない `fog.distance`、`fog.height`、`groundblend` は、常にマップの値を使用します。
- NatureFX は利用者の設定を書き換えません。別のマップに移動した場合、または「Use map profiles」をオフにした場合は、利用者の値がそのまま戻ります。オフの場合は、上記の 2・3 と、マップの素材、発光、ルールをすべて無視します。
- 天候のプリセット（Manual 以外）を選択すると、蓄積の値（`snow` など）はプリセットの値になります。風の強さ、風向き、霧の設定は、プリセットを選択した場合にも適用します。
- `fog.distance` は霧の減衰距離、`fog.height` はカメラの高さから霧が薄れていく高さです。霧の底面はカメラの高さに合わせて移動するため、峠のどの標高でも車の周囲に霧が残ります。雨や霧の天候では、減衰距離が短くなります。

## 2. 頂点カラーによる指定

メッシュの頂点カラーに、揺れ方と雪の積もり方を設定します。頂点カラーは、`[map] vertexColors = true` を指定したマップでだけ使用します。頂点カラーのないメッシュは白 (1,1,1,1) として読み込まれ、全体が最大に揺れる誤った表示になるためです。

| チャンネル | 用途 | 0 | 1 |
|---|---|---|---|
| R | 風の影響の強さ | 揺れない（根元、幹） | 最大に揺れる（枝先、葉先、草の先） |
| G | 揺れの位相のずらし | — | — |
| B | 硬さ | 草のように柔らかい | 動かない |
| A | 空の開け具合 | 屋根の下、橋の下、トンネル | 空が完全に開けている |

- G の値 0..1 は、位相 0..2π に変換します。隣り合う株が同じ動きにならないよう、G には乱数を設定します。
- R、G、B は `NatureFX/Foliage` の揺れに、A は雪、落ち葉、濡れの付き方に使用します。レイトレーシングの影の揺れには、頂点カラーを使用しません。

### 2.1 設定の目安

| 対象 | 設定 |
|---|---|
| 木 | R は高さに比例させる（地面 0、樹冠の上端 1）。幹は R = 0、B = 0.8 前後 |
| 草の株、ササ | R は株の根元 0、先端 1。G は株ごとに乱数 |
| 路面、地形 | R = 0。森の中や崖の下で A を下げると、雪や落ち葉が自然にまばらになる |
| 橋の下、トンネル | A = 0 にすると、雪、落ち葉、濡れが付かない |

### 2.2 OBJ 形式の KN マップに関する注意

OBJ には、頂点カラーの標準的な記述方法がありません。`v x y z r g b` は一部のソフトウェアだけが対応する拡張で、アルファも含みません。
頂点カラーは、Kino Content SDK で作成する `.knmap` でだけ使用できる前提です。OBJ 形式のマップでは `vertexColors = false` のままとし、名前のルールだけを使用してください。

## 3. 天候ゾーンのマーカー

天候ゾーンは、マップの一部だけ天候を変えるための、表示されない箱です。

### 3.1 名前

```
nfx_zone_<id>
```

- `<id>` には英数字と `-` だけを使用できます。`<id>` はプロファイルの `[zone.<id>]` と対応します。対応するセクションがないゾーンは、警告を出力して無視します。
- 空のオブジェクトとして配置し、Transform の拡大率で箱の大きさ（m）を指定します。回転させた箱は、回転を含めて判定します。
- OBJ のマップでは、直方体のメッシュ `nocol_nfx_zone_<id>` として配置できます（4.2）。

### 3.2 設定できる値

`[zone.<id>]` には、`[defaults]` と同じキーに加えて、次のキーを記述できます。`season` は蓄積の値の簡易指定としてだけ機能します。木の色は `[defaults]` の `season` に従います。

| キー | 意味 | 既定 |
|---|---|---|
| `blend` | 縁から外の値へなめらかにつなぐ距離（m） | 20 |
| `priority` | ゾーンが重なった場合の優先度。小さい順に重ね、大きい値を優先する | 0 |

判定はカメラの位置で行います。カメラがゾーンに入ると、縁から `blend` の距離をかけて、値がゾーンの値に近づきます。

### 3.3 設定例

| 目的 | 設定 |
|---|---|
| 峠の頂上付近だけ雪を積もらせる | `nfx_zone_summit` を頂上に配置し、`snow = 0.6` を指定する |
| 谷沿いだけ霧を出す | `nfx_zone_valley` を谷に沿って配置し、`fog.distance = 250` を指定する |
| トンネルの中だけ風を止める | `nfx_zone_tunnel` を配置し、`wind.strength = 0` を指定する |

### 3.4 予定

| マーカー | 内容 |
|---|---|
| `nfx_shelter_<id>` | 箱の中を屋根の下として扱い、雪、落ち葉、濡れを付けない。頂点カラーの A を設定できないマップ向け |
| `nfx_wind_<id>` | 局所的な風（谷を吹き上がる風など）の向きと強さ |

## 4. マーカーの共通書式

5〜7 章で配置する対象は、マーカーで指定します。マーカーの配置方法は次の 4 通りです。どの方法で配置しても、同じものとして読み込みます。

| 配置方法 | 使用できるマップ | 位置、大きさ、向き |
|---|---|---|
| 4.1 空のオブジェクト | SDK のマップ（推奨） | Transform の位置、拡大率、回転 |
| 4.2 メッシュのマーカー | OBJ のマップ | メッシュの境界の箱。向きは名前のキーで指定 |
| 4.3 無効にした標準のコンポーネント | SDK のマップ | Transform と、コンポーネント自身の設定 |
| 4.4 プロファイルの `[markers]` | すべて（公式のコースを含む） | 座標とキー |

マーカーの名前は、次の形式で記述します。

```
nfx_<種類>_<プリセット>[__<キー>-<値>]...
```

- 名前の例は `nfx_light_sodium`、`nfx_puddle`、`nfx_volume_mist__density-0p5` です。
- `<種類>` には `zone` `light` `probe` `grass` `fx` `decal` `puddle` `water` `volume` `forest` `shrub` `shrubproto` のいずれかを指定します。未知の種類は、警告を出力して無視します。
- `__<キー>-<値>` を付けると、プリセットの値を部分的に変更できます。小数は `0p5`（0.5）、負の数は `m30`（−30）と記述します。値を省略した `__<キー>` は `on` と同じ意味です。Blender や Unity が付ける `.001` や ` (1)` などの番号は無視します。
- メッシュを持つマーカーには、先頭に `nocol_` を付けます（`nocol_nfx_...`）。Kino が当たり判定を付けないようにするためです。
- 無効にしたオブジェクトも検索の対象です。このため、マーカーはオブジェクトごと無効にしてもかまいません。

### 4.1 空のオブジェクト

- 位置は Transform の位置、箱の大きさは拡大率（m）、向きは回転で指定します。光源やデカールの向きは、オブジェクトの前方（+Z）です。
- 描画も当たり判定もないため、NatureFX がない環境には影響しません。

### 4.2 メッシュのマーカー（OBJ のマップ向け）

- `nocol_nfx_<種類>_...` という名前の直方体のメッシュ（MeshRenderer 付き）を配置します。位置と大きさは、メッシュの境界の箱から決まります。
- 向きは名前のキー `yaw` と `pitch` で指定します。`yaw` は 0 が +Z（北）で、時計回りです。これは風向きと同じ規則です。`pitch` は 0 が水平、90 が真下です。
- NatureFX がない環境ではメッシュが表示されるため、マテリアルは透明（アルファ 0）にしてください。NatureFX は読み込み時にメッシュの描画を停止します。
- MeshRenderer を持たない `nocol_nfx_...`（MeshFilter だけ）は、マーカーの箱ではなく、草、森、藪、水面を生成する面として読み込みます。

### 4.3 無効にした標準のコンポーネント

HDRP / Unity の標準のコンポーネントを付けたオブジェクトを、`nfx_` で始まる名前で配置します。コンポーネントまたはオブジェクトは、無効にしておいてください。NatureFX が条件に応じて有効にします。明るさ、色、テクスチャなどは、Unity エディターでそのコンポーネントに設定した値をそのまま使用します。

| 種類 | コンポーネント | NatureFX の処理 |
|---|---|---|
| `light` | Light（HDRP の光源） | `when` に応じた点灯と消灯、ちらつき、影付きの光源の数の管理（6.1） |
| `probe` | Reflection Probe | 時刻や天候の変化に応じて描き直す（6.4） |
| `decal` | Decal Projector | 有効にする。ただし、ゲームの HDRP 設定でデカールが無効なため、現時点では表示されない（7.2） |
| `volume` | Local Volumetric Fog | `when` に応じて有効にする（7.4） |
| `fx` | Particle System | Map effects がオンの間、再生する（5.4） |

- 名前のプリセットは省略できます（`nfx_light`）。省略した場合は、点灯条件など NatureFX 側の動作だけをキーで指定します（`nfx_light__when-dusk`）。
- プリセットを記述した場合（`nfx_light_sodium`）、コンポーネントがなければ、NatureFX がプリセットの光源を作成します。コンポーネントがあれば、コンポーネントの値を優先します。

### 4.4 プロファイルでの配置

マップを編集できない場合（公式のコースなど）は、同じマーカーをプロファイルの `[markers]` に座標で記述できます。

```ini
[markers]
# 種類_プリセット = x, y, z [, キー=値 ...]   （ワールド座標、m。size は 幅x高さx奥行き、既定 1x1x1）
light_sodium    = 120.5, 34.0, -88.2, yaw=90, pitch=70
volume_mist     = 300, 10, 450, size=80x20x200
puddle          = 41.0, 12.3, 5.5, size=4x0.3x2
```

- 公式のコースで位置を調べる場合は、F8 > Map の「Copy camera position」を使用します。カメラの位置がクリップボードにコピーされます。
- 面が必要なもの（草、森、藪、水面）と、コンポーネントを使うもの（4.3）は、`[markers]` では配置できません。

### 4.5 数の上限

| 種類 | 上限 | 上限を超えた場合 |
|---|---|---|
| `light` | 描画は 64 個（影付きは 8 個） | カメラに近いものを優先する |
| `probe` | 16 個 | 自動配置のプローブのうち、最も遠いものを外す |
| `decal` | 512 個（描画は 32 個） | カメラに近いものを優先する |
| `puddle` | 16 個 | カメラに近いものを優先する |
| `fx` | 32 個 | カメラに近いものを優先する。80 m より遠いものは停止する |
| `volume` | 32 個 | カメラに近いものを優先する |

## 5. 草・植生

### 5.1 立体の草

NatureFX は、地面の上に草の葉を大量に描画します。板の草（`alpha_grass`）では表現できない密度と立体感を出すための機能です。

#### 生成する場所

- `nocol_nfx_grass_<プリセット>` のメッシュの面の上に生成します。このメッシュには、草を生やす範囲の地面のコピーを使い、MeshFilter だけで配置します。
- `[grass] auto = true` の場合は、`grass_` で始まる走行面にも自動で生成します。種類は `preset` で指定します（既定 `wild`）。静的バッチされた面には生成できません。

#### プリセット

| プリセット | 見た目 | 高さ |
|---|---|---|
| `lawn` | 刈り込まれた芝 | 5〜10cm |
| `wild` | 路肩の雑草（季節によって枯れる） | 20〜50cm |
| `susuki` | ススキ（秋に穂が出る） | 80〜150cm |
| `sasa` | ササ（冬も緑） | 40〜80cm |
| `moss` | 苔（湿った日陰で濃くなる） | 1〜2cm |

| キー | 意味 |
|---|---|
| `density` | 密度（本/m²） |
| `height` | 高さの倍率 |
| `hue` | 色相のずらし（度） |

#### 動作

- 風で揺れます。風向き、風の強さ、突風の値をそのまま使用します。
- タイヤが通過すると倒れ、しばらくすると起き上がります。この動作にはタイヤ跡マップの圧縮を使用します。
- 雪が積もると埋もれます。雪の深さより低い草は描画しません。

#### 描画方法と負荷

- 8 m 四方の区画ごとに草のメッシュを生成します。カメラが近づくと生成し、離れると破棄します。遠い区画ほど葉の数を減らします（全数、1/2、1/4 の 3 段階）。
- 描画距離は、F8 > Map の「3D grass distance」で設定します（既定 60 m）。`lawn` はその半分、`moss` は 3 割の距離です。密度は「3D grass density」で設定します。
- 描画には `NatureFX/Foliage` を使用し、HDRP の光と影を適用します。このため、「Replace shaders」がオンの場合にだけ表示されます。
- 生成する面のメッシュは、読み取り可能に設定する必要があります。
- 影を落とすのは、カメラから 25 m 以内の草だけです。レイトレーシングの影には含まれません。

### 5.2 葉の透過光と色のばらつき

`[foliage]` には、木の種類ごとの見え方を記述します。左辺の判定は `[rules]` と同じで、マテリアル名とオブジェクトの階層パスに正規表現を適用します。

```ini
[foliage]
(?i)alpha_trees_cedar   => type=conifer,   translucency=0.3, variation=0.15
(?i)alpha_trees_broad   => type=deciduous, translucency=0.7, variation=0.3, autumn=red
(?i)alpha_trees_ginkgo  => type=deciduous, translucency=0.6, autumn=yellow
(?i)alpha_sasa          => type=bamboo
```

| キー | 意味 |
|---|---|
| `type` | `conifer`（針葉樹）/ `deciduous`（広葉樹、既定）/ `bamboo`（竹、ササ）/ `grass` |
| `translucency` | 逆光時に葉が透けて明るく見える強さ（0..1）。既定値は種類ごとに異なる（針葉樹 0.25、竹 0.45、草 0.5、広葉樹 0.6） |
| `variation` | 木ごとの色のずらし（0..1、既定 0.2）。乱数は木の位置から生成するため、追加のデータは不要 |
| `autumn` | 広葉樹の紅葉の色。`red` / `yellow` / `mixed`（既定）/ `brown` |

- `[foliage]` に該当した `HDRP/Lit` のマテリアルは、`NatureFX/Foliage` に切り替わります。
- 透過光は、逆光時に法線を太陽側へ傾けて明るくする近似で表現します。

### 5.3 季節の色

季節に応じて、`type` ごとに色を変えます。

| type | 春 | 夏 | 秋 | 冬 |
|---|---|---|---|---|
| `deciduous` | 明るい若葉 | 濃い緑 | `autumn` の色 | 葉を落とす（枝だけになる） |
| `conifer` | 緑 | 緑 | 少し褐色寄り | 暗い緑 |
| `bamboo` | 緑 | 緑 | 緑 | 葉の縁が白く枯れる（隈笹） |
| `grass` | 明るい緑 | 緑 | 黄土色に枯れる | 枯れ草 |

- 季節は F8 > Weather > Season で選択します。Auto の場合、天候のプリセットが Autumn または Snow であればその季節を使い、それ以外の場合はマップの `[defaults] season` を使います。いずれも指定がない場合（None を含む）は、色を変えません。
- 季節を変更すると、約 30 秒かけて次の季節へ移行します。移行は木ごとに少しずつずらします。
- 冬の広葉樹は、葉の切り抜きを強めて葉の量を減らします。落とした葉も、レイトレーシングの影には残ります。

### 5.4 生き物と舞うもの

`nfx_fx_<プリセット>` の箱の中に、細かい粒子を発生させます。粒子は、条件（季節、時刻、天候）を満たす場合にだけ発生します。自作の Particle System を無効にし、`nfx_fx` という名前で配置することもできます（4.3）。この場合は条件を判定せず、Map effects がオンの間だけ再生します。

| プリセット | 発生するもの | 条件 |
|---|---|---|
| `fireflies` | ホタル | 夏の夜、雨でないとき |
| `leaves` | 舞い落ちる葉 | 秋。風が強いほど多い |
| `petals` | 桜の花びら | 春 |
| `moths` | 灯りに集まる虫 | 夏の夜。点灯中の光源マーカーの近くにも自動で発生する |
| `dust` | 日差しの中の塵 | 晴れの日中 |
| `pollen` | 綿毛、花粉 | 春〜初夏 |

| キー | 意味 |
|---|---|
| `amount` | 量の倍率 |

- 季節を指定していない場合（None）は、季節に依存しないものだけが発生します。対象は、夏の夜のホタルと虫、落ち葉が多いときの落ち葉、塵です。

### 5.5 遠景の森

`nocol_nfx_forest_<conifer|broadleaf|mixed>` のメッシュ（MeshFilter だけ）の面に、十字に組んだ板（インポスター）の木を 2km 先まで並べます。マップで作成していない山肌を埋めるための機能です。

| キー | 意味 |
|---|---|
| `density` | 100m² あたりの本数（既定 2） |
| `height` | 木の高さ（m）。既定 22、`broadleaf` は 14 |

- 木は風で揺れ、季節の色と冬の落葉も反映します。遠方では本数を減らします。影は 200m まで描画します。

### 5.6 藪（スキャンの低木）

スキャンした低木を、GPU インスタンシングで数千本描画します。表示は距離に応じて 3 段階に切り替えます。

| 距離 | 描画内容 |
|---|---|
| 近距離（F8 > Map の「Scanned shrubs up to」、既定 25 m） | スキャンしたメッシュ |
| 近距離の 3 倍まで | ビルボードクラウド。スキャンを 20〜50 枚の板で近似したもの |
| 300 m まで | オクタヘドラルインポスター。上半球の N×N 方向から焼き付けた画像を、視線の向きに応じて切り替える 1 枚の板 |

どの段階も `NatureFX/Foliage` で描画するため、「Replace shaders」が必要です。風、季節、雪、透過光を反映します。独自エンジンのシーンには全低木の板の束が含まれ、影と反射に表示されます。

マップには、低木ごとのひな形と、生成する面を配置します。

```
nocol_nfx_shrubproto_<名前>__frames-8     空のオブジェクト（どこに置いてもよい）。frames はインポスターの N（既定 8）
  nfxproto_lod0       スキャンのメッシュ（MeshRenderer はオフ）。原点に立たせる
  nfxproto_cloud      板の束のメッシュとマテリアル（オフ）
  nfxproto_impostor   1 枚の板とインポスターの絵のマテリアル（オフ）
nocol_nfx_shrub_<名前>+<名前>__density-0p8__scale-1p2    生やす面（MeshFilter だけ、読み取り可）
```

| キー | 意味 |
|---|---|
| `density` | 1 m² あたりの本数（既定 0.15）。この値に F8 > Map の「Thicket density」を乗じる |
| `scale` | 大きさの倍率。1 本ごとに ±25 % のばらつきを加える |

- 40° より急な面には生成しません。
- 向きは 1 本ごとにランダムです。
- 季節の色は、`[foliage]` でマテリアル名（スキャンの葉のマテリアル `nfxshrub_`）に対して指定します。

#### 描画の負荷

- スキャンは 1 本で最大 15 万三角形あります。スキャンで描画するのは、近距離の範囲内でカメラに最も近い 40 本までです。残りは、近距離の範囲内でも板の束で描画します。
- 影は独自エンジンがレイトレーシングで描画します（板の束が独自エンジンのシーンに含まれるため）。HDRP の影マップには描画しません。
- 低木は動かない物として扱い、カメラの動きだけで動きベクトルを作ります。風の揺れは、動きベクトルに含めません。
- 低木を多数配置すると、独自エンジンのシーンに抜きのある板が多数入るため、レイトレーシングの負荷が上がります。重い場合は、F8 > Map の「Thicket density」を下げてください。

#### ひな形の作り方

1. Blender で、Poly Haven のスキャンから板の束とインポスターの画像を焼き付けます。焼き付ける低木は、スクリプトの `SHRUBS` に（名前、アセット、ノード）の組で記述します。
   ```bash
   blender -b --factory-startup --python tools/kino_sdk/bake_shrub_lods.py -- %USERPROFILE%\NatureFX-Deps\polyhaven %USERPROFILE%\NatureFX-Deps\shrubs
   ```
   - インポスター：上半球の 8×8 方向から、1 方向 256 px で焼き付け、2048 px の画像にまとめます。
   - 板の束：スキャンの三角形を、位置と向きの近いもの同士で 32 枚の板にまとめ（k-means）、板ごとに正面から焼き付けます。
   - 環境変数 `NFX_SHRUBS_ONLY=shrub02a,fern02` を指定すると、その低木だけを焼き付けます。
2. 焼き付けた結果を、HDRP/Lit が読む PNG に変換します。
   ```bash
   python tools/kino_sdk/shrubs_to_png.py %USERPROFILE%\NatureFX-Deps\shrubs <SDK>/Assets/Content/NfxAssets/shrubs
   ```
   `<名前>_cloud_diff/_nor/_mask.png`、`<名前>_impostor_diff/_nor/_mask.png`、および板の位置を記した `shrubs_unity.json` を作成します。
3. マップのシーンに、ひな形と生やす面を配置します（次の「ひな形の決まり」）。
   - ひな形：`nfxproto_lod0` にスキャンを、`nfxproto_cloud` に `shrubs_unity.json` の板（角の座標と画像上の範囲）から作ったメッシュを、`nfxproto_impostor` に 1 枚の板を置き、それぞれに焼き付けた画像のマテリアル（HDRP/Lit、抜きあり、両面）を割り当てます。
   - レンダラーはすべてオフにします。静的バッチの対象にはしません（統合されると NatureFX が個別に描画できないため）。
   - 生やす面：低木を生やす範囲を覆う平らなメッシュを、`nocol_nfx_shrub_<名前+名前>__density-…__scale-…` という名前で MeshFilter だけ付けて置きます。

焼き付け済みの低木（実寸）は次のとおりです。小さいものは `scale` で大きくして使用してください。

| 名前 | スキャン | 高さ |
|---|---|---|
| `shrub01` | shrub_01_a | 0.4 m |
| `shrub02a` | shrub_02_a | 1.7 m |
| `shrub02c` | shrub_02_c | 1.3 m |
| `shrub03a` | shrub_03_a | 0.4 m |
| `shrub04` | shrub_04 | 0.2 m |
| `fern02` | fern_02_b | 0.4 m |

#### ひな形の決まり

自作のひな形を使う場合は、次の決まりに従ってください。

- 座標は、低木の根元の中心を原点とし、地面を y = 0 とします。
- `nfxproto_impostor` の板は、x 方向が幅、y 方向が高さで、大きさはインポスターの 1 コマと同じにします。NatureFX は、板の大きさと中心の高さをメッシュの範囲から読み取ります。
- インポスターの画像は、半八面体（hemi-octahedral）の配置で N×N コマを並べます。各コマの法線は、そのコマのカメラの向き（x 右、y 上、z 手前）で格納します。
- `nfxproto_cloud` のメッシュは、頂点カラーの R に根元からの高さの割合（風の揺れの大きさ）、G に揺れの位相を入れます。

## 6. 光

### 6.1 光源マーカー

`nfx_light_<プリセット>` の位置に、HDRP の光源を配置します。Unity エディターで無効にした Light を配置した場合は、その明るさ、色、形状のまま、NatureFX が点灯を管理します（4.3）。

| プリセット | 種類 | 色温度 | 明るさ | 既定の向き |
|---|---|---|---|---|
| `sodium` | 高圧ナトリウム灯（橙色の街灯） | 2000K | 12000 lm | 真下 |
| `mercury` | 水銀灯（古い青白い街灯） | 4200K | 10000 lm | 真下 |
| `led_street` | LED の街灯 | 4500K | 9000 lm | 真下 |
| `tunnel` | トンネル照明（橙） | 2000K | 4000 lm | 真下 |
| `vending` | 自動販売機の前面 | 6000K | 1500 lm | `yaw` の向き |
| `floodlight` | 投光器（駐車場など） | 5000K | 30000 lm | `yaw`・`pitch` |
| `beacon` | 黄色の点滅灯 | 黄 | 800 lm | 全方向 |
| `lantern` | 提灯、常夜灯 | 2200K | 300 lm | 全方向 |

| キー | 意味 |
|---|---|
| `lm` | 明るさ |
| `k` | 色温度 |
| `range` | 到達距離（m） |
| `yaw` `pitch` | 向き（下記を参照） |
| `spot` | スポットの角度 |
| `shadow` | `on` / `off` |
| `flicker` | 古い蛍光灯のようなちらつき（0..1） |
| `when` | `night`（既定）/ `dusk`（夕方から）/ `always` |
| `ies` | `off` で配光を使用しない（6.7） |

- 点灯は太陽の高度で判定します。`dusk` は太陽の高度 6〜10°、`night` は −1〜3° で点灯します。点灯する高度は街灯ごとにずれるため、一斉には点灯しません。ナトリウム灯と水銀灯は、数秒かけて明るくなります。
- 向きは次の順に決まります。`yaw` `pitch` を記述した場合は、その値を使います。記述がない場合は、空のオブジェクトの回転を使います。回転していない場合は、プリセットの向き（街灯は真下）を使います。
- `vending` は、面光源の代わりに前方へ向けた広いスポットライトです。面光源は、レイトレーシングのランプに含まれないためです。
- 霧の中では、ランプの光の筋が見えます。
- 光源の器具のモデルは、マップ側で配置してください。マーカーが提供するのは光だけです。
- F8 > Map の Lights に、点灯中の数、描画中の数、影付きの数が表示されます。

### 6.2 発光マテリアル

`[emissive]` で、マテリアルを夜だけ発光させます。

```ini
[emissive]
(?i)led_sign       => nits=800,  k=6500, when=always
(?i)window_house   => nits=60,   k=2700, when=night, random=0.6
(?i)vending_front  => nits=400,  k=6000, when=always
```

| キー | 意味 |
|---|---|
| `nits` | 明るさ（cd/m²、既定 100）。現実の単位のため、露出と自然に整合する |
| `k` | 色温度（既定 6500） |
| `when` | `night`（既定）/ `dusk` / `always` / `off` |
| `mask` | 発光させる範囲。`bright`（既定、色テクスチャの明るい部分）/ `alpha`（テクスチャのアルファ）/ `full`（面全体） |
| `random` | 点灯している割合（0..1）。家の窓などを、場所ごとに点灯または消灯させる |
| `flicker` | ちらつき（0..1） |

- `random` と点灯のずれは、ワールド座標の 6m 四方の区画ごとに決まります。Kino のマップでは静的バッチによってオブジェクトがまとめられ、オブジェクト単位で区別できないためです。
- `[emissive]`、`[materials]`、`[terrain]` に該当した `HDRP/Lit` のマテリアルは、置き換えルールがなくても NatureFX のシェーダーに切り替わります。この場合、雪や濡れも付くようになります。

### 6.3 再帰反射

白線、標識、デリネーター（視線誘導標）、ガードレールの反射板が、ヘッドライトの光を入射方向へ返して光って見えるようにします。

設定は、`[materials]`（7.1）で `retro` を指定して行います。

```ini
[materials]
(?i)markings        => asphalt_paint, retro=0.6
(?i)warning_sign    => metal_painted, retro=1.0
(?i)delineator      => plastic, retro=1.0
```

- `retro = 1` は標識の反射シート（約 300 cd/lx/m²）、`0.6` は白線程度（約 5）に相当します。光が返るのはヘッドライトの近くだけです。このため、運転席の視点では強く、車の後方の高い視点では弱く光ります。
- 対象は、カメラに近い 4 台分のヘッドライトです。
- 雨で白線が水に覆われると、反射が弱くなります。これは現実と同じ挙動です。

### 6.4 反射プローブ

車体や濡れた路面に映り込む景色を、その場所に合ったものにします。

- `nfx_probe` は、映り込みが変わる場所（森の中、トンネル、開けた場所）に配置します。空のオブジェクトの場合は、箱の大きさが影響範囲になります。箱が 2m 以下の場合は、60×30×60m を影響範囲とします。無効にした Reflection Probe の場合は、その影響範囲の設定を使用します（4.3）。
- `[probes] auto = true` の場合は、道路に沿って `spacing`（既定 60m）ごとに自動で配置します。道路の形状はマップから取得できないため、車が走行した位置に配置します。16 個を超えた場合は、自動配置のプローブのうち最も遠いものを外します。
- 時刻や天候が変わると、カメラに近いものから順に、1 フレームに 1 面ずつ描き直します。
- この機能は、F8 > Map の「Map reflection probes」で切り替えます。独自エンジンの空（F8 > Sky & fog の「Native sky」、既定オン）を使用している間は、この機能を使用しません。空の映り込みは独自エンジンの空が、近くの物体の映り込みはレイトレーシングの反射が担当するためです。

### 6.5 夜の背景

```ini
[night]
skyline = 180      # 街明かりの方角（度。0 = +Z、時計回り）。書いたときだけ街明かりを置く
distance = 3000    # m
spread = 70        # 広がる角度
height = -150      # カメラからの高さ（m。麓の街なら負）
lights = 900       # 灯りの数
stars = true       # 星（既定 true）
```

- 星は夜に表示され、雲が多いと隠れます。「Native sky」がオンの場合は、独自エンジンが星を描画します。オフの場合は、トラックの空が HDRP の Physically Based Sky であるときに限り、NatureFX が星を描画します。`stars = false` を指定すると、どちらの場合も星を表示しません。
- 街明かりは夜だけ点灯します。表示するのは光の点だけで、街の上空が明るくなる表現はありません。

### 6.6 空と雲

- 雲は天候の雲量に応じて増え、山に雲の影が流れます（F8 > Sky & fog の Clouds and stars）。
- 雲海は `[clouds] sea = <高さ m>` で指定します。朝と雨上がりに、雲の層がその高さ（上面）まで下りてきます。峠の上から谷を見下ろす景観を表現できます。雲海は HDRP の体積雲で描画するため、「Native sky」がオフの場合にだけ表示されます。
- 遠くの山が青く霞んで見えます（F8 > Sky & fog の「Distant haze」）。

### 6.7 街灯の配光とレイトレーシングの影

- `sodium` `mercury` `led_street` は道路に沿って細長く広がる配光（バットウィング）、`tunnel` は広く均一な配光、`floodlight` は中心が強い配光です。道路の向きは光源の x 軸で、`yaw` で回転させます。`ies=off` を指定すると、配光を使用しません。
- 「Ray traced shadows for every lamp」（既定オン）がオンの場合、すべての街灯の影をレイトレーシングで描画します。この場合、影付き 8 灯の制限はなくなります。対象は、カメラに近い 128 灯までです。1 画素あたりの影は、16 灯以下の場合はすべての灯から、16 灯を超える場合は 8 つの候補から選んで付けます（ReSTIR の最初の段階）。

## 7. 素材とオブジェクト

### 7.1 素材の指定

`[materials]` で、マテリアルに現実の素材を割り当てます。素材によって、濡れ方、汚れ方、経年変化が変わります。

```ini
[materials]
(?i)road_asphalt     => asphalt_old
(?i)masonry          => masonry, moss=0.6
(?i)guardrail        => metal_galvanized, rust=0.2
(?i)concrete         => concrete, stain=0.4
(?i)rock             => rock, moss=0.3
(?i)curve_mirror     => mirror
```

| 素材 | 濡れたとき | 経年変化（キー） |
|---|---|---|
| `asphalt_old` / `asphalt_new` | 暗くなり、水たまりができる。新しいほど黒く、粒が細かい | `wear`（ひび、白っぽさ） |
| `asphalt_paint` | 滑らかに光る | `wear`（かすれ） |
| `concrete` | 濃い灰色にしみる | `stain`（雨だれの黒い筋） |
| `masonry` / `rock` | 継ぎ目から先に濡れる | `moss`（日陰や上向きの面に苔） |
| `metal_galvanized` / `metal_painted` | 水滴が玉になる | `rust`（錆。縁と下側から進む） |
| `glass` | 水滴が流れ落ちる | `dirt` |
| `plastic` / `wood` / `soil` | 素材ごとの吸水の度合いで濡れる | `dirt` |
| `mirror` | 水滴が付く | 完全な金属の鏡になる（7.7） |

次のキーは、単位を記載したもの（m）を除き 0..1 で指定します。素材名の後に記述すると、その素材の値を上書きします。

| キー | 意味 |
|---|---|
| `porosity` | 濡れたときの暗くなり方（吸水） |
| `moss` `rust` `stain` `wear` `dirt` | 上の表の経年変化 |
| `beading` | 水滴が玉になる度合い |
| `retro` | 再帰反射（6.3） |
| `antitiling` | テクスチャの繰り返しを目立たなくする（六角形のタイルでずらす） |
| `variation` / `variation_size` | 広い範囲の明るさと粗さのむら / むらの大きさ（m、既定 20） |
| `groundblend` | 接地のなじませの高さ（m、7.8）。0 でこの素材だけ無効にする |
| `albedo` | 反射率（色の明るさ、線形の輝度）。`0.12` で固定値、`0.08-0.14` で範囲、`off` で調整しない。既定は素材ごとの実測範囲（下表） |

素材を指定したマテリアルは、カラーマップの平均の明るさが実物の反射率の範囲に入るように、ベースカラーを 0.4〜2.5 倍の範囲で調整します（設定「マップの素材を実際の反射率に合わせる」）。テクスチャの模様はそのまま残ります。調整した値はログに `Albedo:` の行で出力されます。

| 素材 | 反射率の範囲 |
|---|---|
| `asphalt_old` | 0.07〜0.15 |
| `asphalt_new` | 0.03〜0.07 |
| `asphalt_paint` | 0.45〜0.75 |
| `concrete` | 0.20〜0.45 |
| `masonry` | 0.12〜0.35 |
| `rock` | 0.10〜0.35 |
| `wood` | 0.10〜0.35 |
| `soil` | 0.07〜0.25 |

### 7.2 デカール

`nfx_decal_<プリセット>` の箱の中の地面に、上から模様を描画します。ゲームの HDRP 設定ではデカールが無効なため、NatureFX のシェーダーが描画します。このため、模様は NatureFX のシェーダーの面にだけ表示されます。無効にした Decal Projector を `nfx_decal` という名前で配置することもできます。ただし、ゲームがデカールを有効にしない限り表示されません（4.3）。

| プリセット | 模様 |
|---|---|
| `crack` | 路面のひび割れ（既定） |
| `patch` | 補修跡（色の違うアスファルトの継ぎはぎ） |
| `oil` | 油染み（濡れると虹色に光る） |
| `leaves_pile` | 落ち葉の吹き溜まり（落ち葉の量に応じて増える） |
| `sand` | 砂、砂利の散らばり |
| `skid` | 古いブラックマーク（ブレーキ跡） |
| `moss_edge` | 路肩の苔、土の汚れ |
| `slow_dots` | 減速を促す破線（車線を横切るブロックの列） |
| `zebra` | ゼブラ（導流帯の枠と斜線） |
| `speed_30` / `speed_40` / `speed_50` | 路面の速度表示（+z の側から読める向き） |
| `joint` | 橋や伸縮の継ぎ目 |
| `manhole` | マンホールの蓋 |
| `worn_line` | かすれた白線 |

| キー | 意味 |
|---|---|
| `yaw` | 模様の向き |
| `opacity` | 不透明度 |

- 模様は、NatureFX が描いた 128px の画像です。大きさは空のオブジェクトの拡大率で指定します。x が幅、z が長さ、y が上下の到達範囲です。拡大率が小さすぎる場合は 4×1×4m を使います。向きは Y 軸の回転または `yaw` で指定します。
- 描画するのは、カメラに近い 32 個までです。雪や落ち葉は、デカールの上に積もります。

### 7.3 水たまりと水面

#### `nfx_puddle`

雨で水がたまる場所を指定します。水は箱の中央から広がり、強い雨では約 1 分半で満ちます。雨がやむと、10 分ほどかけて引きます。雨粒の波紋と映り込みも表示します。

| キー | 意味 |
|---|---|
| `amount` | 水の量（0..1、既定 1） |

- 表示するのはカメラに近い 16 個までです。NatureFX のシェーダー（`NatureFX/LitAccumulation` など）の面にだけ表示されます。

#### `nocol_nfx_water_<プリセット>`

常に水がある場所を指定します。水面の形のメッシュを、MeshFilter だけで配置します。

| プリセット | 水面 |
|---|---|
| `stream` | 沢、小川。`yaw`（指定がなければ Y 軸の回転）の向きに流れる |
| `gutter` | 側溝。雨で水位が上がる（キー `rise`、既定 0.08m） |
| `pond` | 池。風でさざ波が立つ |

- 水面は不透明な暗い面で、映り込みによって水に見せます。

### 7.4 煙・湯気・霧の源

`nfx_volume_<プリセット>` の箱の中に、局所的な霧を配置します。HDRP の Local Volumetric Fog に、動くノイズを適用して描画します。自分で設定した Local Volumetric Fog を無効にし、`nfx_volume` という名前で配置することもできます（4.3）。この場合は `when` だけに従います。

| プリセット | 見た目 | 条件 |
|---|---|---|
| `mist` | 谷を這う霧（既定） | 早朝、雨上がり |
| `steam` | マンホールや側溝の湯気 | 寒い日（雪がある日、または冬） |
| `smoke` | 煙突や焚き火の煙 | `when` で指定（既定は常時） |
| `road_steam` | 雨上がりの路面から立つ湯気 | 雨がやんでから 10 分以内の晴れ間 |
| `haze` | 遠くの霞 | 晴れた日中 |

| キー | 意味 |
|---|---|
| `density` | 密度 |
| `when` | `always` / `night` / `dusk` / `day` |
| `yaw` | 煙が流れる向き（既定は風向き） |

- 条件を満たすと 8 秒ほどかけて濃くなり、条件から外れると薄れて消えます。表示するのは、カメラに近い 32 個までです。
- 「Native fog」（既定オン）がオンの場合は、独自エンジンの 3D の霧（カメラに近い 64 個の箱）で描画します。オフの場合は、HDRP のボリューメトリックフォグで描画します。表示中は NatureFX がボリューメトリックフォグをオンにします。ただし、ゲームのフレーム設定で無効になっている場合は表示されません。

### 7.5 法面と崖（[terrain]）

```ini
[terrain]
(?i)cliff_|slope_ => triplanar, tile=4, steep=rock_mat, flat=grass_mat, slope=0.55, blend=0.15, noise=0.5, maptile=4
```

| キー | 意味 |
|---|---|
| `triplanar` | 色テクスチャを 3 方向から貼る（急な面でテクスチャが縦に伸びない） |
| `tile` | テクスチャ 1 枚の大きさ（m、既定 4） |
| `steep` / `flat` | 急な面と平らな面に使う、マップ内のマテリアルの名前。そのマテリアルの色テクスチャを使用する。`steep` を指定しない場合は、地の色を灰色の地層模様にした岩肌になる |
| `slope` `blend` `noise` | 岩肌になり始める傾き（0 が平ら、1 が垂直、既定 0.55）、境界の幅（既定 0.15）、境界の乱れ（既定 0.5） |
| `maptile` | `steep` `flat` のテクスチャ 1 枚の大きさ（m、既定 4） |

- 変更するのは色だけです。法線マップはメッシュのものをそのまま使用します。
- HDRP/Lit の法線マップは、そのまま使用できます。視差オクルージョン（POM、`_PIXEL_DISPLACEMENT` + ハイトマップ）も、NatureFX のシェーダーで機能します。

### 7.6 冬の路面

- 寒い日（雪がある日、または冬）に、路面が濡れていて雨が降っていない場合は、1 分ほどかけてブラックアイス（滑らかな氷の膜）になります。晴れた昼は薄くなります。
- 雪の日は、車が走行した場所に轍ができ、その脇に押しのけられた雪が積もります。轍はタイヤ跡マップから生成します。

### 7.7 カーブミラー

鏡面のマテリアルに、`[materials]` で素材 `mirror` を割り当てます。マテリアルは完全な金属の鏡になります。映る景色はレイトレーシングの反射で描画するため、Ray traced reflections が必要です。

### 7.8 接地・汚れ・散らばるもの

独自エンジンは、地面の地図を作成します。地図の範囲はカメラの周囲 128 m、間隔は 12.5 cm です。地図には、真上から見た地面の色、高さ、向き、路面か地面かの区別、および草木に覆われているかどうかが含まれます。7.8.1〜7.8.6 の機能は、この地図を使用します。

- 機能は、F8 > Map の「Ground detail」で切り替えます。独自エンジンが必要です。塗る汚れとデトリタスは、「Map effects」もオンの場合にだけ機能します。
- 地面として扱うのは、地形（`terrain`）と、動かない幅 6 m 以上の平たいメッシュです。このうち、マテリアル名またはメッシュ名に `road`、`asphalt`、`tarmac` を含むものを路面として扱います。

#### 7.8.1 接地のなじませ

岩、擁壁、縁石、支柱、木の根元など、地面に刺さっている物体の下部を地面の色にします。下ほど地面の色が濃くなり、境界はノイズで崩します。高さは、マップの既定値（`[defaults] groundblend`、m）または素材ごとの値で指定します。

```ini
[materials]
(?i)retaining_wall => concrete, groundblend=0.6
(?i)guardrail_post => metal_galvanized, groundblend=0.15
(?i)sign           => metal_painted, groundblend=0      # 0 でこの素材だけ切る
```

草の葉と、抜きの葉（カード）には適用しません。

#### 7.8.2 高さを使った混ぜ方

苔、汚れ、土ぼこり、落ち葉、雪は、表面の低い部分（石の隙間、ひび、目地）から先にたまります。高さマップを持つマテリアルは高さマップを使用し、持たないマテリアルは色の明るさを使用します。色の明るさを使う場合は、暗い部分を低い部分とみなします。設定は不要です。

#### 7.8.3 塗る汚れ（[paint]）

位置を指定して、泥はね、水しみ、轍を描画します。点は `x,y,z`（ワールド座標、m）で表し、`;` で区切って並べます。オプションは `|` の後に記述します。

```ini
[paint]
# 路肩の泥はね: 幅 width m、地面から height m の高さまで
mud   = 120,402.1,-30; 160,403.0,-12; 210,404.2,6 | width=1.5 height=0.6 strength=0.8
# 擁壁の下の水しみ: 壁の足元の線、そこから height m 上まで（既定 1.0）
stain = 300,410,80; 340,411,95 | height=1.2
# 轍の黒ずみ: 路面の上、幅 width m（既定 0.4）
rut   = 120,402.1,-29.2; 210,404.2,6.8 | width=0.35 strength=0.6
```

この機能は、頂点カラーの代わりに、メッシュを変更せずに汚れを描くためのものです。カメラの周囲 256 m を 0.5 m 単位で描画し、カメラが 64 m 移動すると描き直します。

#### 7.8.4 細かいもの（デトリタス）

路面と地面の境界から 2 m 以内に、小石、落ち葉、小枝の 3D の粒を配置します。

- 粒は主に地面（路肩）の側に配置します。路面の上には、路肩から 0.6 m 以内にだけ、少量（3 割程度）を配置します。
- 種類の割合は、小石 6 割、落ち葉 2.5 割、小枝 1.5 割です。大きさは 1 粒ごとに 0.5〜1.5 倍の範囲でばらつきます。
- 配置は格子に沿わないように、位置を連続的にばらつかせています。
- 密度は F8 > Map の「Debris (pebbles, twigs, leaves)」で変更できます（0 で無効）。
- カメラが 24 m 移動すると、周囲に配置し直します。配置し直しの計算は数フレームに分けて行うため、走行中に処理が止まることはありません。
- マップ側での設定は不要です。路面のマテリアル名またはメッシュ名に `road`、`asphalt`、`tarmac` が含まれていれば機能します。

#### 7.8.5 草木の下の地面

草むら、藪、低い枝の下とその周囲 1 m 程度の地面を、草木の陰になった湿った土や落ち葉の色に近づけ、少し暗く、つやを消します。草むらと裸の地面の境界が線にならないように、広がり方にはむらを付けています。

- 地面の地図を作るときに、真上から地面に向けて光線を飛ばし、地面より先に草木（抜きのある物、または風で揺れる物）に当たった場所を「覆われている」と記録します。地面から 3 m までの高さにある草木が対象です。
- 適用するのは地面だけです。路面には適用しません。
- マップ側での設定は不要です。草木のマテリアルが `NatureFX/Foliage` に置き換わっていれば機能します（「Replace shaders」と「Foliage too」がオン）。

#### 7.8.6 草木のカードの根元

草や葉のカード（抜きのある `NatureFX/Foliage`）が地面に刺さっている部分を、地面になじませます。

- 地面から 35 cm までを、根元ほど暗くし、地面の色に近づけます。
- 地面から 7 cm までを、ばらばらに欠けるように消します。カードが地面に刺さった部分の直線が見えなくなります。消し方は画面、影、奥行きのどれでも同じです。
- 3D の草（5.1）とインポスター（5.6）には適用しません。3D の草は、独自に根元を暗くしています。
- マップ側での設定は不要です。カードの下端は、地面より少し下まで埋めて配置してください。地面より上に浮いていると、浮いた部分はそのまま見えます。

### 7.9 まっすぐな線を崩す（マップ側の加工）

自然の中には、定規で引いたようなまっすぐな線や、完全に平らな面はありません。モデルの輪郭が直線のままだと、どれほど質感を良くしても作り物に見えます。マップを組み立てるときに、メッシュそのものを変形して線と面を崩します。

NatureFX の機能ではなく、マップ側（Unity の組み立てスクリプト）で行う加工です。表の関数名は実装例の名前で、作り方の目安として挙げています。

| 対象 | 加工（関数） | 内容 |
|---|---|---|
| 地形 | `RoughTerrain` | 数 m の起伏と小さな凸凹で、最大 ±0.3 m 上下させます。路面の縁から 1.5〜6 m、構造物から 0.8〜3 m の範囲で徐々に効かせ、路面や擁壁との接合部は動かしません。法線も起伏の傾きに合わせて傾けます。 |
| 擁壁 | `RoughWalls` | 三角形を 256 分割（約 6×20 cm）し、表面のテクスチャの高さマップで実際に凹凸を付けます（間知ブロック ±3.5 cm、石積み ±4.5 cm）。あわせて、数 m 単位のはらみ（±5 cm）と、天端の線の上下（数 cm）・欠けを加えます。 |
| 縁石、側溝、グレーチング | `RoughKerbs` | 三角形を 16 分割し、道路に沿って 1〜2 cm 揺らし、少したわませます。ずれ方は世界座標で決めるため、隣り合う部材はつながったまま動きます。 |
| 木の幹 | `Trunk` | 道路から 25 m 以内の杉は 16 角柱にし、辺ごとに半径を ±7 % 変えて、縦の筋を輪郭に出します（広葉樹は 12 角、±4 %）。根元は 35 % 太くします。 |
| 路面の外縁 | `EdgeStrips` | 路面の外側の縁に沿って、地面側 0.5 m から路面側 1 m までの帯を重ね、土、落ち葉、苔で縁の直線を隠します。路面側ほどまばらにします。 |

加工の決まりは次のとおりです。

- 変形するのは描画用のメッシュだけです。当たり判定（コライダー）は元の形のまま残し、走行に影響させません。地形だけは、植物を地面の起伏の上に置くために、変形後のメッシュを当たり判定にも使います。
- 隣り合うメッシュの継ぎ目が開かないように、変形量は位置だけで決まる共通の関数（ノイズ）から求めます。
- 細かく分割するため、三角形の数が増えます。分割は、道路から見える範囲の構造物に限ってください。

高さマップによる視差（POM）は輪郭を変えません。深い POM は斜めから見ると段々の縞が出るため、浅く（2 cm 程度、サンプル数 64 / 16）し、大きな凹凸はメッシュの変形で表現してください。
