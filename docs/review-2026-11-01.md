## 3. 契約の確認（問題なし）
- `NfxPayload` 68 B = `kPayloadBytes`、`Frame` cbuffer の添字（0..51、ライト 52 + k×512、`NFX_MAX_LOCAL_LIGHTS` 128 = `LocalLights.Max`）、`TraceEventData` 8448 B、`NrdEventData` 328 B、シェーダーテーブルの整列、P/Invoke 署名はすべて一致。
- `_NFX_*` の 100 以上のプロパティ名・型・配列長は C# とシェーダーで一致。コンピュートのディスパッチ数は `(n+7)/8`。
- NRD の 2D モーションベクトルの符号・単位、`roughness = sqrt(alpha)` は NRD の期待どおり。
- プロファイルの解析は InvariantCulture、キーと既定値は `docs/map-authoring.md` と一致。星の等級→照度の計算は正しい。
- AGENT.md の「NFX_MAX_LOCAL_LIGHTS 32 / 564 float / kConstantSlot 2304」は古い記述（今は 128 / 2100 float / 8448）。

## 4. 確認の仕方（ゲーム内）
- B1/B16/B26/P12: バンドル再ビルド後、テストマップの道路・岩の法線（ハイライトの向き）が正しいか、吹きだまりの影が面に乗るか、ヘックスの形。
- B2: 車同士の反射にリバリーが映るか、ガラスの屈折スライダーが効くか（Mod の再ビルドのみ）。
- B3: F9 で「PHOTO · n / 256 frames」が進むか、暗視スライダーが効くか。
- B4: 曇りの天候で Sun override をオフ→太陽の影が戻り、月が消えるか。
