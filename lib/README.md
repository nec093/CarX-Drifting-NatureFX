# lib

KSL の SDK ファイルをここに置きます (リポジトリには含めていません)。

[ksl_sdk の Releases](https://github.com/trbflxr/ksl_sdk/releases) から最新の `ksl_sdk_<version>.zip` (1.0.5 以降) を取得し、`API/` の中身をここにコピーしてください。

- `KSL.API.dll`
- `KSL.API.xml` (コード補完用、任意)
- `0Harmony.dll`

同じ zip の `maykr.exe` は `tools/` に置きます。`.ksm` のビルドに使います。

> リポジトリ本体 (master) の `sdk/` に入っている maykr は古く、KSL のサーバーが 404 を返します。必ず Releases の zip を使ってください。
